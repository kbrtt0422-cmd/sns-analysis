# コミュニケーション記録

オーナー(BIORA)とCEO(Jobs)間のやり取りのうち、重要な指示・報告・承認を記録する。

## 記録ルール
- ファイル名: `NNN_YYYY-MM-DD_件名.md`
- 形式:
  ```
  # NNN: 件名

  - 日付: YYYY-MM-DD
  - 発信: BIORA（オーナー） / Jobs（CEO）

  ## 内容
  （指示・報告・承認の内容）

  ## 対応・結論
  （ある場合）
  ```
- 日常会話は記録しない。方針決定・承認・重要な報告のみ記録する。
- より重い意思決定は `operations/decisions/` に記録する（こちらは経緯のメモ）。
