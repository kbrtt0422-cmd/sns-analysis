## ①キャプション・フィード投稿文の書き方

### フィード投稿作成の5ステップ（4-3より）
1. **第一画像（表紙）を作る**
2. **本文ページ（中身の解説）を作る**
3. **まとめページを作る**
4. **エンドページ（締め）を作る**
5. **キャプション文を作る**

### 第一画像のルール
- 文字数は**13文字ルール**：表紙のメインテキストは13文字前後に収めると視認性・タップ率が高い。
- 避けるべき6つの失敗パターン（チェックリスト化）
  - [ ] 文字が小さすぎて読めない
  - [ ] 情報量が多すぎて一目で内容が伝わらない
  - [ ] フォントや色がバラバラで世界観が崩れている
  - [ ] ターゲットが誰なのか分からない表現になっている
  - [ ] ありきたりすぎて他の投稿と差別化できていない
  - [ ] ベネフィット（読むとどう得するか）が書かれていない

### 本文ページのポイント
- 1ページ1メッセージに絞る（情報を詰め込みすぎない）。
- 「結論→理由→具体例」の流れで各ページを構成する（後述のPREPの法則と同じ考え方）。

### まとめページの構成
- 本文で話した内容を箇条書きで要点だけ再掲する。
- 「結局何が言いたかったか」を一文で言い切る。

### エンドページに入れる5要素（チェックリスト）
- [ ] 保存を促す一言（「保存して見返してください」等）
- [ ] フォローを促す一言
- [ ] プロフィールへの誘導
- [ ] 関連投稿・ハイライトへの誘導
- [ ] コメント・DMを誘発する一言

### キャプション作成の基本姿勢
- キャプションは「投稿の補足」ではなく「もう一押しの接客」として書く。
- 冒頭1〜2行で「誰のための投稿か」「読むと何が得か」を提示するのが基本フック。

## ②表紙作成のポイント

### フォローにつながる3ステップ（3-10より）
1. **競合・同ジャンルの伸びている表紙を集める**（自分のジャンルだけでなく他ジャンルも参考にする）
2. **なぜそのデザイン・コピーが伸びているのかを分解する**（フォント、配色、文字数、訴求の角度）
3. **自分のジャンル・ターゲットに当てはめて作り直す**（コピーそのままの流用はNG、"構造"だけ抽出する）

### 表紙作成チェックリスト
- [ ] 13文字前後のメインコピーになっているか
- [ ] 一目で「誰向け」か分かるか
- [ ] 競合と同じコピーの丸パクリになっていないか（構造だけ借りる）
- [ ] リールからのフォロー導線を意識した「続きが気になる」設計になっているか

## ③ストーリーの文章テンプレート

### ストーリー運用の基本（5-1より）
- ストーリーは「フィードより閉鎖的だが、関係構築（教育・ファン化）に最も効くツール」と位置づける。
- 日常投稿は単体では機能しない。有益発信で信用を積んだ土台があってこそ効果を持つ。

### 上手なストーリーデザインの7テクニック（5-5より、そのまま再現）
1. **背景色を変える**：毎回同じ背景にしない。視覚的な変化で「手が止まるストーリー」を作る。
2. **太字テキストの強調トリック**：重要な一言だけ太字＋大きめフォントにする。
3. **文字の一部だけハイライト**：全文ではなく一部の単語だけ背景色（マーカー風）をつけて視線を集める。
4. **直線・ライントリック**：図形の直線を使って視線の流れを誘導する（矢印や下線など）。
5. **改行を適切に入れる**：2行以上になる文章は必ず改行し、圧迫感を消す。
6. **文字と余白のバランスを取る**：詰め込みすぎず、余白を作って読みやすさを優先する。
7. **線（ライン）のクオリティを上げる**：装飾線・図形のクオリティがそのまま世界観の質に直結する。

### 引き込まれる文章構成の7ポイント（7-6より、そのまま再現）
01. **PREPの法則で話を展開する**
02. **線のストーリーを意識する**
03. **文字の大きさや余白などの使い分け**
04. **背景を変えて視覚的な変化をつける**
05. **ストーリーはLIVE感を意識する**
06. **講義ではなく対話形式**
07. **感想はどんどん載せていく**

#### ①PREPの法則（詳細・テンプレート）
P（Point結論）→ R（Reason理由）→ E（Example具体例）→ P（Point結論）の順で書く。

- **悪い例（PREPなし、美容品紹介）**：
  「この美容液最近使ってるんですが結構良くて、肌がもち上がる感じがあって、配合成分も良くて、知り合いにも勧めてます。」
  → 結論が後回し・話が長く、何が言いたいのか伝わりにくい。

- **PREP適用後（同内容）**：
  - P：「このリフトアップ美容液、本当におすすめです。」
  - R：「理由は、配合されている成分がハリ・弾力に直接効くからです。」
  - E：「実際に2週間使ったら頬のたるみが気にならなくなりました。知り合いにも勧めたら同じ反応でした。」
  - P：「だからこの美容液は本当におすすめです。」
  → 結論が最初と最後にあるので、読み手の理解と納得感が一気に上がる。

**テンプレ化**：
```
【結論】〇〇は本当に△△です。
【理由】なぜかというと□□だからです。
【具体例】実際に〇〇したら△△という結果になりました。
【結論（再提示）】だから〇〇は△△です。
```

#### ②線のストーリーを意識する
- ストーリーズの正式名称通り「物語」を意識する。1トピックにつき**3枚以上**で構成するのが目安。
- NG：「なんとなくネタがないから上げる」日常投稿。
- OK：「目的を持って意識付けのために上げる」日常投稿。
- 日常投稿が機能するのは、有益発信による信用の土台があってこそ。

#### ③文字の大きさ・余白の使い分け
- 最初に見てほしい一言は文字を大きくする。
- 2行以上になる場合は必ず改行を入れる。
- 改行がなく圧迫感のあるストーリーは最後まで読まれない。

#### ④背景を変えて視覚的な変化をつける
- 背景を毎回変化させることで「手が止まるストーリー」を作る。
- 背景写真は第一印象に直結するため、変化がないとスルーされやすい。

#### ⑤LIVE感を意識する（テンプレ）
- 文章の入り出しに「ついに！」「すごい！」など感情をむき出しにした言葉を使う。
- 講義的に長く話すと一気に読まれなくなるので、ライブ配信のような臨場感を入れる。

#### ⑥講義ではなく対話形式
- 「〇〇についてどう思いますか？」のような問いかけを混ぜ、一方通行の説明にしない。
- ストーリーは物語であり講義ではない、という意識を持つ。

#### ⑦感想はどんどん載せていく
- ストーリーは拡散力がなく閉鎖的なため、ユーザーの感想・DMを載せることで「臨場感」「他の人も行動している空気」を作る。
- 感想を載せる＝客観的な意見を見せる。質問を載せる＝「DMすれば返ってくる」という安心感を与える。
- テンプレ：感想ストーリーの最後は「リンクで終わらせず」自分の価値観の話に広げて締める（母の日エピソードのように、感想→DM紹介→自分の価値観発信、の流れに広げる）。

## ④ファン化テクニック

### ファン化の目的（6-1より）
- 流れは「集客 → 教育 → 販売」。ファン化は教育フェーズの中核。
- フォロワーの離脱は自然現象であり、気にしすぎず「理想のファン層」を明確化するワークが重要（どんな人に向けて発信したいかを言語化する）。

### 7つのファン化テンプレート（6-2より、そのまま再現）
ゴールを決めてから、以下のテンプレートを組み合わせて発信する。

1. **有益な情報の発信**
2. **過去の自分とユーザーを重ねた発信**
3. **自己投資の重要性を説く発信**
4. **挑戦や行動することの重要性を説く発信**
5. **共通の敵を作る発信**
6. **価値観の発信**
   - 構成要素：①過去の体験 ②失敗体験や成功体験 ③事象に対する考え方
7. **権威性や専門性の発信**
   - 構築の3ステップ：01 資格を取る　02 美容の本などをたくさん読み込む　03 色々なSNSから知識をつける

> 「これら7つのストーリーにおけるファン化テンプレートを参考にしながら自分の発信をしていきましょう」（教材原文）

### 真のファン化テクニック＝「仮想敵を作る」（6-3より、そのまま再現）
3つの否定軸：
1. **自分自身の過去（過去比較）**：過去の自分（できなかった自分・知らなかった自分）を否定軸にする。
2. **業界の構造の否定**：個人ではなく業界構造・仕組みそのものを否定する。
3. **風潮の否定**：社会的な風潮・考え方を否定する。

**絶対ルール（原文ママ）**：
> 「1番大切なことは、特定の個人を否定したり、その人自身を否定したり、競合他社の否定を直接的にしていくことをせず、必ず否定する場合には、仮想敵を否定していくようにしましょう。」

## ⑤コメント誘発テクニック

### ショート動画教科書 10-3「爆発的にコメントを誘発させる方法」（そのまま再現）

**前提**：再生数の多い動画はコメント欄自体がエンタメ化している。コメント欄を盛り上げることが再生数・拡散に直結する。

**よくある失敗**：「みなさんは〇〇についてどう思いますか？コメントで教えてください」という直接誘導は、すでにファンになっている人しか反応しない。

**ファンになる前の人からコメントを取る方法**：
- マウントを取りたい人／否定的な意見の人の感情を揺さぶる要素を盛り込む。
- 批判的な内容のほうが議論・コメントが盛り上がりやすい（芸能スキャンダル型の構造）。

**コメントを爆増させる3ステップ（テンプレ化）**
1. コメント数が多い投稿を見つけ、批判的なコメントをピックアップする。
2. そのコメントから逆算して動画・キャプションの内容を考える。
3. 想定していたコメントが来たら、賛否が割れそうなリプライを少し返す。

**アンチコメントへのマインドセット**
- アンチ＝「エンゲージメントを高めてくれる協力者」と捉え直す。
- 大切なのは批判内容を真似するのではなく「なぜその要素が突っ込まれるのか」という心理を理解して応用すること。
- 視聴者の中に「あれ？これって変じゃない？」「みんなどう思ってるんだろう」と思わせる要素を仕込むのがコツ。

**注意点（チェックリスト）**
- [ ] 教育系・権威性重視のジャンルで炎上ネタを扱っていないか（信頼を失うリスクが高い）
- [ ] 社会的モラルを欠いた発信になっていないか
- [ ] 特定個人や実在の企業を直接否定していないか（④の仮想敵ルールと同様の注意が必要）

## ⑥爆売れするストーリーテンプレート（訴求・セールス型）

### 7ステップの訴求テンプレート（7-3より、そのまま再現）
1. **興味を惹く**
2. **解決策の提示**
3. **問題提起**
4. **危機感や緊急性**
5. **未来の提示**
6. **利用者の感想**
7. **価値観の共有**

#### 各ステップの実践ポイント
1. **興味を惹く**：1枚目で「お待たせしました感」「ようやく発表できる感じ」を演出する。事前の教育・興味づけがあることが前提。
2. **解決策の提示**：おすすめ商品とリンクを必ずセットで提示。ハイライトを含め3枚以内に購入先リンクを入れる。
3. **問題提起**：なぜおすすめするのかを自分の過去の悩みから語る。「潜在的な悩み（言語化できていない）」を「顕在的な悩み（具体的に言語化された状態）」に変換する。
4. **危機感や緊急性**：悩みを理解させるだけでは人は動かない。放置することの危険性・早く解決すべき理由を訴求する。
5. **未来の提示**：商品を手にした後の理想の未来をイメージさせる。注意：⑤だけを単独で出すと「自分には関係ない」と思われるため、③④を経た上で提示することが重要。
6. **利用者の感想**：成約率向上に最も強い要素。購入報告・感想をストーリーに掲載し、「購入報告待ってます！」のような言葉を入れる。「周りも行動している」雰囲気作りが鍵。使い方の共有まで載せるとより丁寧。
7. **価値観の共有**：最後は商品リンクで終わらせず、自分の価値観発信で締める。

**最終チェックリスト**
- [ ] 有益な情報だけで終わっていないか
- [ ] 最後のストーリーがリンクで終わっていないか
- [ ] 自分の価値観発信で訴求シリーズを締めているか

## まとめ：使う順番の目安

1. 表紙（②）で止める → 13文字ルール・競合分解の3ステップ
2. 本文・キャプション（①）で伝える → PREP（③①）で構成する
3. ストーリーで関係を深める（③⑤デザイン7技/文章7ポイント）
4. ファン化テンプレート（④7つ）・仮想敵（④）で「自分ごと化」させる
5. コメント誘発（⑤）でエンゲージメントと拡散を作る
6. 訴求が必要な場面では7ステップテンプレート（⑥）で成約まで導線を作る
