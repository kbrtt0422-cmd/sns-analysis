# テロップ（動画内文字）ノウハウ

> 出典: 実際のバズ動画（100万再生規模）のテロップ分析セッションより抽出。
> ジャンル別（グルメ紹介型・Vlog型）のテロップスタイルを実例つきでテンプレート化。

---

## ①共通ルール（ジャンル横断）

- **" "（波線引用符）で囲って強調**：強調したい単語・フレーズを`"　"`で囲む。
- **`…`で余韻・間を作る**：断定せず含みを持たせたい箇所に使う。
- **価格は`¥〇〇〇`形式**：「3500円」ではなく`¥3,500`のように通貨記号＋カンマ区切りで表記する。
- **「〇〇とは思えない」で価値を強調**：ギャップ訴求の定番フレーズ（例：「3,500円とは思えないクオリティ」）。
- **ターゲット・店名を名指しして締める**：「〇〇好きにおすすめ…！ 店名」のように、最後にターゲット層と固有名詞をセットで置く。
- **場所・店名の紹介は最後に置く**：冒頭で店名を出すと「保存したから見なくていい」と離脱されるため、店名がわからないと最後まで見る理由が生まれる構成にする（視聴維持率対策）。詳細は③参照。

## ②グルメ紹介型テロップ（例：だるま津田沼店）

### 完成版テンプレート
```
　　🥹　　🍺
個室なのに〇〇円の
△△に連れてってもらった 〃

* 友達に誘われてついてきたら
* 🍗 まず出てきたのが 🍗
* どでかい〇〇🔥
* サイズがバグってる
* 👀 次に来たのが 👀
* 〇〇🧀
* 〜すぎてた🤤✨
* 🎡 そして〇〇が 🎡
* 〇〇で来た…かわいい🥺
* 🍽️ これぜんぶ食べ飲み放題 🍽️
* ¥〇,〇〇〇（税込）
* 〇,〇〇〇円とは思えないクオリティで
* しかも全席個室🥹
* また絶対来る🍺✨
* 📍店名
* 最寄駅 徒歩〇分
```

### 構成の意図（4パート）
| パート | 役割 |
|---|---|
| 冒頭（数字の衝撃：価格や条件） | 「え何？」で視聴を止める |
| 料理・見どころ2〜3連発 | 驚きを積み重ねて離脱させない（例：揚げ物→チーズ→焼鳥のように種類の異なる驚きを順に積む） |
| 価格・お得感の再提示 | 「保存しよ」と思わせる |
| 店名・場所 | 最後に置き、最後まで見ないとわからない設計にする |

### 転用のコツ（型を変えずに中身だけ差し替える）
既にバズった動画の型をそのまま流用し、ワードだけ自ジャンルに置き換える。
- 「食いしん坊女子に誘われて」→「友達に誘われてついてきたら」
- 「9割とは思えないサイズ」→「価格とは思えないクオリティ」
- 「アイスの大きさもバグで」→「〇〇のサイズもバグで」（対象物だけ差し替え）
- 「〇〇好きにおすすめ…！ 店名A」→「〇〇好きにおすすめ…！ 店名B」

### 感情語での言い換え（初稿→改訂で強くなった変化）
テンポを軽く・友達に話しかけるような口調にするため、説明的な文末を感情語に変換する。
- 「〜円で」→「意味わからん…🥹」
- 「サイズが大きい」→「サイズがバグってる」
- 「よく伸びる」→「糸引きすぎてた🤤✨」

## ③Vlog型テロップ（例：沖縄旅行）

### スタイルの特徴
- **セクション見出しを絵文字で左右に飾る**：`🌺 〇〇 🌺` `🌙 夜なのでごはん 🌙` のように、見出しの前後に同じ絵文字を配置して場面転換を示す。
- **📍で場所を示す**：新しいスポットに移動するたびに`📍店名・スポット名`を単独行で置く。
- **語尾は口語・感情系で統一**：「〜したよん」「〜すぎた」「〜！」「〜🥹」「〜🤤」など、友人に話すような口調で統一する。丁寧語（です・ます）は使わない。
- **短文でテンポよく積み重ねる**：1行1情報。説明を長く書かず、体験の切れ端を淡々と並べる。

### 冒頭（タイトル）の絵文字配置パターン
セクション見出しのように左右対称に絵文字を揃えるのではなく、**文字の周囲に絵文字を散らして配置**する。
- 白い細め手書きフォントを想定。
- `〃`（ノノ点・繰り返し記号）や記号でリズムをつける。
- タイトルは2行に分けて短く区切る。

例（3案）：
```
案①
🍺✨ 友達と行った
神すぎる居酒屋の記録 〃
　　　👯‍♀️　　　🎉

案②
　👀　　　　✨
津田沼で見つけた
コスパ最強居酒屋 〃🍺

案③（数字を冒頭に入れて強い）
　　🥹　　🍺
個室なのにハイボール190円の
居酒屋に連れてってもらった 〃
　　　　　　　💕
```
→ 案③のように**具体的な数字（価格等）を冒頭1〜2行目に入れる**と、読んだ瞬間に「え？」と止まりやすく最も強い。

## ④視聴維持率を上げる構成原則

- **場所・店名の紹介は最後に置く**：冒頭で出すと「保存したからもういい」と離脱される。店名がわからないまま話が進むことで、最後まで見る動機を作る。
- **数字（価格・特典条件）は冒頭に近い位置で早めに見せる**：驚きの起点にする。
- **見どころは種類の異なる驚きを2〜3個、順番に積み重ねる**：同じ種類の驚きの繰り返しではなく、ジャンルの異なる要素（例：料理の見た目→量→価格）を積むことで飽きさせない。
