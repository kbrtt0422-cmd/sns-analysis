# リール台本ノウハウ

本ファイルは「ショート動画の教科書」5-1〜5-7、「インスタ運用の教科書」3-1・3-7の合計9資料から、リールの企画リサーチ・台本作成・冒頭フック・アルゴリズムに関する実践的ノウハウを抽出・統合したものです。抽象論ではなく「具体的に何をどう作るか」を中心にまとめています。

## ①企画リサーチ・バズリサーチの方法

### リール作成の全体フロー（6ステップ）
①リサーチ → ②台本作成 → ③撮影 → ④編集 → ⑤キャプション作成 → ⑥投稿
- 最重要工程は①リサーチ。リサーチは「カンニング」と同義であり、根拠のない自己判断で企画を作ると失敗しやすい。
- 初期はフィード投稿よりリール優先。発見欄からの流入率はフィード21%に対しリール44.4%（データ比較）。リールはフィードより圧倒的にリーチが取りやすく、TikTok・YouTubeショート・LINE VOOMなど他プラットフォームにも転用できる。

### 企画考案の手順（全体像）
STEP①企画・ネタを決める → STEP②冒頭の見せ方/ワード/編集方法の共通点を探す（なる式バズリサーチ）→ STEP③台本に落とし込む → STEP④撮影 → STEP⑤編集

### 動画の3つの目的と運用順序
1. 認知の獲得（有益情報ベース。最も拡散しやすい）
2. ファン化促進（価値観・人生のストーリーを語る）
3. ものを売る（アフィリエイト等）

運用順序：最初は認知獲得動画のみで進め、10〜15投稿できた段階でファン化動画を追加してブースト。
- 例外：「100日後にモテ男になる」のようなストーリー仕立て企画は、1投稿目からストーリーを入れる必要がある。
- 実例：DJ社長（レペゼン地球）型の運用は「過激投稿で認知獲得 → ストーリー仕立て投稿でファン化」という順番。

### 有益企画のリサーチ方法（3つ）
**①ショート動画分析**
- TikTokとLEMON8で、自分のジャンル・コンセプト名を検索する。
- 企画が強い特徴＝検索上位に似た企画が複数並ぶ／再生回数が高い／感謝コメントが多い。
- 「個人の影響力」か「企画の強さ」かを見極める基準：
  - 情報発信型でその投稿だけ突出して伸びている → 企画が強い
  - 個人系でフォロワーが少ないのに伸びている → 企画が強い
  - 影響力ある人で全投稿が安定して伸びている → 個人の影響力（企画単体の強さではない）

**②YouTube分析**
- ジャンル名＋キーワードで検索。上位動画＝需要が高いテーマ。
- コメント欄で情報の質・視聴者の満足度を確認する。

**③ネタ帳作成**
- 普段からバズ分析する癖をつけ、企画ストックを常時メモしておく。

### バズのリサーチ（なる式バズリサーチ、3ステップ）
①発見欄でおすすめリールをひたすらスクロール（自分の発見欄から。リールタブは無作為に表示されるため使わない）
- 気になる動画の再生回数を確認（目安：100万再生以上、または平均との比較）

②冒頭7秒を分析し仮説を立てる
- 最重要は冒頭1〜2秒。
- バズる要素は以下3種のいずれか、または組み合わせのみ：
  - **ビジュアルフック**＝映像で手を止める（例：人がご飯を食べるシーン）
  - **サウンドフック**＝音（例：咀嚼音、ASMR、懐メロBGM）
  - **バーバルフック**＝言葉（例：「コレ、夫を沼らせた悪魔の壺ネギ」）

③そのアカウントに飛び、バズっている投稿とバズっていない投稿の共通点を探して仮説検証
- バズる発信者は要素を理解した上で同じ要素を繰り返す傾向があるため、これが検証の手がかりになる。
- 注意点：他の動画で共通点が当てはまらなくても「まだ気づかれていない／試されていないだけ」の可能性がある。複数の発信者で同じ共通点が見られれば信頼度UP。
- 実例：語学アカウントで平均1000回再生だったところ、冒頭フックの改善で30万回再生に成長。

### リサーチ実行チェックリスト
- [ ] 自分の発見欄を毎日スクロールする習慣をつけたか（リールタブではなく発見欄を使う）
- [ ] 気になった動画は再生回数とコメント数を必ず確認したか（コメント100件以上を目安に注目）
- [ ] 冒頭1〜2秒のフック種別（ビジュアル／サウンド／バーバル）を分類してメモしたか
- [ ] 同じ発信者の他の投稿も見て、バズった投稿・バズらなかった投稿の差分を比較したか
- [ ] 複数の発信者で同じ共通点が見られるかをクロスチェックしたか（1人だけの傾向は再現性が低い）
- [ ] TikTok・LEMON8・YouTubeでジャンル名検索を行い、競合の上位投稿の型を確認したか
- [ ] ネタ帳（メモアプリ等）に企画ストックを蓄積する仕組みを作ったか

### リサーチで見るべき指標の優先順位
1. 再生回数（絶対値、またはそのアカウントの平均との比較）
2. コメント数・コメントの質（質問・感謝・共感コメントが多いか）
3. 保存数（インサイトが見える場合）
4. 同ジャンル・同コンセプトの投稿が検索結果に複数並んでいるか（企画自体の需要の強さの裏付け）

## ②冒頭フックの作り方

### バーバルフック3ポイント
**①「知らないと損するかも」**
- ターゲットを具体的に表す。NG例：「美容好きな人は」のような抽象的すぎるターゲット設定。
- 損したくない心理の3段ステップ：
  1. 自分ごと化させる
  2. 「これが手に入るよ」という餌を見せる
  3. それが手に入らない場合の損失を伝える

**②「知っておくとお得かも」**
- 強いワード・権威性ワードと「見ないと損」を掛け合わせる。

**③「？を少し残す」**
- 結論を全部言わない。バランスが重要（言いすぎても言わなさすぎてもNG）。

### 「？」を生み出す7つのトリガー
1. 検証企画系（どうなるの？例：「1日結婚してみたら検証」）
2. 常識破壊系（なんで？人間の当たり前を覆す。例：「焼肉は絶対冷凍してください」37.9万回再生）
3. ビフォーアフター系（どうやったの？劇的変化。例：「鼻痩せマッサージ」200万回再生）
4. 権威性×論争系（この人はどう思うの？例：「奢り奢られ論争」40万回再生・345コメント）
5. プライベート公開系（普段見れない秘密をチラ見せ。例：「102歳美容部員の朝ごはん」全投稿100万回超）
6. 結末予想不能系（最後まで目が離せない展開）
7. ランキング形式（どれが1位？1つ目は自信のあるものを配置。例：「プロから見た設備TOP10」91万回再生）

### バーバルフックを磨く実践4ステップ
STEP1：徹底的にリサーチ（伸びている動画30本を見て、冒頭3秒のワード・感情・「？」の生成源をメモ）
STEP2：自分の動画用に変換
STEP3：冒頭の共通点を探す
STEP4：毎週アップデート

### 冒頭の3パターン（実践版）
①ばか得そう！知りたい！と思ってもらえる冒頭
②損しそう！知りたい！と思ってもらえる冒頭
③どーゆーこと！？まじ！？続きは！？なにそれ！？と先が見たくなるようにハテナを残す冒頭

### 冒頭ワードの作り方の本質
- 興味を引きつけるワードは小手先のテクニックに過ぎない。**ワードと映像がマッチしているか**が本質的に重要。
- 弱いワード例：「本日引っ越してきました」
- 改善例：「ある事があり本日引っ越してきました」→「あることって何だろう…？」という興味を生む。
- 実例：このワード＋玄関から下を向いて登場する映像の組み合わせで426万回再生・1投稿で3万人フォロー・平均再生時間22秒を記録。

### 何選系企画の構成ルール
- 最後に強い企画を置くのではなく、**1番最初に最も強い企画を持ってくる**。
- 理由：リール視聴人数は動画内で最初が最も多く、秒数が経つごとに必ず減っていく。最初の期待値が低いと、後ろに良い企画があっても離脱されて見られない。
- 例：「高くてもやって良かった美容医療」では、肌がボコボコでインパクトのあるリジュランを1番目に配置し、冒頭1秒でビフォーアフターを見せて興味を引いた。
- 応用：強い企画が2つある場合は最初と最後に配置し、「動画の最後にプレゼントがある」のように冒頭で予告して離脱を防ぐ（テロップで常に表示し続けるとさらに効果的）。実例：配布資料が2800人以上に受け取られた。

### 冒頭フック作成チェックリスト
- [ ] 冒頭1〜2秒でビジュアル・サウンド・バーバルのいずれかのフックが入っているか
- [ ] バーバルフックが「知らないと損／知っておくと得／？を残す」のいずれかに当てはまるか
- [ ] ターゲットが具体的に表現されているか（抽象的な「〜好きな人」になっていないか）
- [ ] 結論を全部言わず「はてな」が残っているか
- [ ] ワードと映像（最初に見せる画）がマッチしているか（ワード単体の強さだけに頼っていないか）
- [ ] 何選系の場合、1番強い企画を最初に置いているか
- [ ] 7つのトリガー（検証／常識破壊／ビフォーアフター／権威性×論争／プライベート公開／結末予想不能／ランキング）のどれを使うか意識して選んだか

### 冒頭フックのNG例とOK例（言い換えパターン）
- NG：「美容好きな人は見て」→ OK：「毎日メイクに30分かかってる人へ」（具体的な状況指定）
- NG：「今日あった話を聞いてください」→ OK：「子作りを拒否された残念妻の話」（結論を先出し）
- NG：「これ知ってると便利です」（弱い）→ OK：「これ知らないだけで毎月5000円損してます」（損失の具体化）

## ③台本作成の手順・構成テンプレート

### PREP法（基本構文）
Point（ポイント）→ Reason（理由）→ Example（例）→ Point（ポイント）の順で話す、相手に伝わりやすい話法。
- そのまま使うと「Reasonで話が完結してしまい離脱されやすい」「Pointのインパクトが甘くなる」ため、リールではそのまま使わない。

### リール用PREP法（実践構成）
1. **（ポイント）**：何が知れるのかをインパクトのある伝え方で示し、結論を全部言わずに「はてな」が生まれる部分を残す。
2. **（共感）**：そのテーマをさらに知りたくさせる共感ポイント／見るべき理由を入れて自分ごと化させる。
3. **（本題）**：解決策を提示。
4. **（ポイント）**：結論とまとめ／してほしい行動を促す。

### 7秒ルール
- 冒頭の「ポイント＋共感」パートまでで大体5〜7秒。
- 7秒間視聴された動画は、その後の離脱率がかなり低くなる傾向がある。最後まで見てもらえる確率は7秒を超えると高まる。
- → 冒頭の入りとその後の共感部分の作り込みに最も時間をかけるべき。

### 共感パートの作り方（2方式）
①「わかる〜それな〜」型：あるあるネタ・季節ネタ・トレンドネタ・悩みの共感で「これって自分のことだなぁ」と思わせ、相手の心を止める。
②「まじか〜！？それは見ないと！」型：当たり前に見える冒頭や、見ただけで満足されがちな企画で有効。意外性・失敗を煽る内容を入れる。
- 例：「猫影ポーズ撮り方」（120万回再生）→ 冒頭で見ただけで撮り方がわかってしまうため、「撮り方を間違えると影が映らない／ダサくなるから注意」と伝えて、見ないといけない理由を直後に追加。

### 映像台本の重要性
- テキスト台本だけでなく映像台本も用意する。
- 映像台本の1番の目的は「自分でシーンを想定すること」ではなく、**魅力的な参考映像＋ロールモデルカットを見つけておくこと**。
- 自分で考えるより「バズ映像を真似る」方が再現性が高い。「手が止まった映像」をスクショして保存し、それを参考に撮影する。
- 映像台本を組むのは基本的に**冒頭の数カットのみ**でOK（全行程を参考探しすると労力がかかりすぎる）。時間があれば途中のカットにも応用するとより良い。
- 参考ソースの例：小紅書（RED、中国版アプリ）。VLOG系発信者の「動き」「見せ方」「ファッション」「画角」が参考になる。中国系アプリのため登録情報の取り扱いは自己判断。

### PREP法以外の台本パターン
- 〇〇何選系
- 他人からのメッセージ引用系
- レシピ系（冒頭で数字とギャップを見せる）

### PREP法以外（ストーリー・物語形式）の台本作成・具体的4STEP
理解より先に手を動かす方が習得が早いタイプの台本作成法。
①自分がやりたい投稿テイストで、バズっている競合の投稿を10本ピックアップ（同じ構成でバズっているもの、コメント100以上のものを優先）
②10本全て文字起こし（文字起こしツール例：Notta、無料でも使用可。日本語以外にも幅広く対応）
③導入（冒頭の入り）／展開／締めをざっくり分けると、バズる構成パターンが見えてくる
④その型に自分の内容を当てはめて台本を完成。よく使われている音源・映像も確認し、自分のストーリーに乗せる

### 台本を書くときの注意点（3つ）
①語尾被り：「〜です。〜です。〜です。」のように同じ語尾を続けない。
②事実だけをつらつら語らない：商品説明や事実のみだと飽きられる。リアルな自分の感情・体験を入れて自分ごと化させる。
③冒頭で何が言いたいのか分からない：客観的に「全く知らない他人」として読んでみて興味が持てるか確認する。
- 例：「今日あった私の悲しかった話聞いてください」→弱い。「私は子作りを拒否された残念妻」→具体的な結論から入ることで気になる度が確実に上がる。

### 台本作成の実務フロー（テンプレートシート活用）
- 台本作成テンプレートシート（Googleスプレッドシート形式）を使い、リール用PREP法の4パート（ポイント／共感／本題／ポイント）を埋めていく形で作成すると初心者でも作業しやすい。
- 台本完成後は台本作成チェックシートで抜け漏れを確認する運用フローが推奨されている（語尾被り・事実だけ羅列・冒頭の伝わりにくさなど、上記の注意点3つを中心に再チェック）。
- 台本ができたら撮影に進む。撮影段階では映像台本（冒頭数カットの参考映像）に沿って画角・シーンを再現する。

### 台本作成 実践チェックリスト
- [ ] 冒頭（ポイント）でインパクトのある一言＋はてなが残っているか
- [ ] 共感パートで「わかる〜」型か「まじか〜」型のどちらを使うか意図的に選んだか
- [ ] 共感パートまでで5〜7秒以内に収まっているか
- [ ] 本題（解決策）が悩みや必要な情報にしっかり応えているか
- [ ] 結論パートで「保存して」「フォローして」など具体的な行動を促しているか
- [ ] 語尾が同じパターンで3回以上連続していないか
- [ ] 感情・体験などリアルな要素が事実情報だけでなく入っているか
- [ ] 映像台本（冒頭数カットの参考映像）を別途用意したか

## ④リールアルゴリズムの基本

### 拡散の仕組み
リール投稿はフォロワー数に関わらず、まずランダムに数十人へ表示される。そこでの滞在時間・いいね数・保存数などの反応が良いと、100人→300人→500人→1000人と段階的に拡散される仕組み（公式発表ではなく仮説ベース）。

### シャドウバン等の誤解
再生数が伸びない理由を「シャドウバンされている」「過去の投稿が悪くて評価が下がっている」とする説明は誤り。Instagram側にとって良い投稿を抑制するメリットはない（拡散するほど滞在時間が伸びてプラットフォームの得になる）。

### 再生が伸びない本当の原因
シンプルに「投稿のクオリティの問題」。再生数＝その投稿の評価と捉えるべき。外部要因（シャドウバン等）に目を向けても改善につながらない。クオリティの問題と捉えることで次の改善策が見つかり、試行錯誤が進む。

### 後伸びのケース
クオリティが高い投稿でも、初期にInstagram側のジャンル認知が済んでいないため伸びず、後から（投稿を重ねた後に）全体的な再生数が伸びてくるケースがある。
- 実例：美容アカウントで最初は100再生前後が続き、10投稿目あたりで1本バズり、その後過去投稿も含めて全体が数万〜数十万再生に伸びた。
- 再生が伸びないからとアーカイブするのは時期尚早な場合がある。**10〜20本投稿しても再生が変わらない場合**を「クオリティ問題」を疑う目安にする。

### 爆発的にリールを伸ばす極意（12のポイント）

1. **全ての撮影に三脚を使う**：手ブレはユーザー離脱の原因。三脚は高さ160cm以上伸びるものがおすすめ。
2. **ライトを使う**：暗い映像は画質の低下・印象の悪化につながる。編集で明るさを上げると画質が落ちるため、撮影時にライトで対応する。
3. **最初の1〜3秒が最重要**：競合分析でも最初の入りのワード・映像に注目する。実例「本日入居しました」→「ある事があり本日入居しました」に変更し、ワードと映像（玄関から下を向いて登場）をマッチさせたことで426万回再生・3万人フォロー・平均再生時間22秒を記録。
4. **動画のテンポを早める**：カットを細かく入れ、同じ画角を続けない。倍速の使用は「慌ただしくチープに見える」ため非推奨。倍速ではなくカット数を増やす・ズームで画角を変えることでテンポを作る。基本は1シーン1〜1.5秒でカット。
5. **編集後の1コマは1〜2秒以内**：3秒同じ画角が続くと離脱率が急上昇する。実例：冒頭3秒が同じ画角で関係ない内容だった投稿は再生数20万回に留まった。
6. **不要な間はどんなに短くてもカットする**：0.1秒の無駄も削る。「神は細部に宿る」を意識する。
7. **2秒以上同じ視点にならないようにする**：同じ画角の撮影でもズームでカットを分けると別カットに見え、飽きを防げる。
8. **アフレコは気持ち1.5倍速で話す**：
   - 普通の速度だと丁寧すぎてゆったりしたアフレコになり離脱を招く。
   - 語尾は「〜だよ」「〜ね」より言い切り表現（「おすすめ！」等）を使う。
   - 冒頭から間を空けずアフレコを開始し、話せるところまで一気に話す（細かく区切らない）。
   - 吐息・リップノイズ（唇や舌が立てる雑音）はストレス・離脱の原因になるため除去する。
9. **何選系企画は1発目に強いコンテンツを持ってくる**（②の冒頭フック項目で詳述）。
10. **コメントをもらう導線を考える**：コメントが多いほど滞在時間が伸び、外部リーチされやすくなる。具体策5つ：
    - ①メインとは別にコメントが来そうな要素を画面に写す（例：壁に動く時計を表示してコメント誘発）
    - ②アーティスト・YouTuber・人気ドラマなどをさらっとシーンに入れてファンからのコメントを誘発
    - ③音源選定でコメントを誘発（例：大阪人なら知る地下鉄音源を使用し、コメント604件・1000万回再生を記録）
    - ④タイムリーなネタを入れる（例：SHEINからTEMUへの流行の変化を捉えた投稿で1000万回再生）
    - ⑤コメント欄に自分で最初にコメントし、コメントしやすい環境を作る（例：「11月の美容代教えて」）
11. **いいね・コメントマークに文字を被らせない**：テロップ位置はUIの表示位置（右下のいいね・コメントアイコン、上部のキャプション）と被らないようにする。
12. **画質の鮮明さを重視する**：画質が悪いだけで伸びが変わるほど重要。iPhoneは14・15以降の機種推奨。加工アプリ使用は画質を落とすため、純正カメラを使用する。

### 撮影・編集の実務チェックリスト（12ポイント運用版）
- [ ] 三脚を使用したか（手持ち撮影は手ブレで離脱を招く）
- [ ] 部屋の明るさが不足していないか、ライトで補ったか
- [ ] 最初の1〜3秒で結論やインパクトのあるワード・映像を入れたか
- [ ] カットを1〜1.5秒単位で細かく割っているか（倍速で誤魔化していないか）
- [ ] 同じ画角・同じシーンが2〜3秒以上続いていないか
- [ ] 不要な間（無音・無動作の時間）を徹底的にカットしたか
- [ ] アフレコは1.5倍速の感覚で話し、言い切り表現を使っているか
- [ ] 吐息・リップノイズが入っていないか確認したか
- [ ] コメントを誘発する仕掛け（小道具・音源・タイムリーなネタ・自分の先行コメント）を1つ以上入れたか
- [ ] テロップがいいね・コメントアイコンやキャプション表示位置と被っていないか
- [ ] 画質が劣化していないか（純正カメラ使用、対応機種か）を確認したか

### アルゴリズム理解のまとめ
- リールの再生数はランダムな初期表示からの段階的拡散で決まる仕組みであり、外部要因（シャドウバン等）ではなく投稿クオリティそのものが評価対象になっていると理解する。
- 短期的な再生数の伸び悩みだけで判断せず、10〜20本という投稿数を目安にクオリティ改善のサイクルを回す。
- 後伸びの可能性があるため、安易な投稿のアーカイブは避ける。
- 視聴維持率（特に冒頭7秒・3秒ルール）とコメント誘発の仕組みが、拡散の起点となる初期反応（いいね・保存・滞在時間）を左右する最重要指標である。

## 台本制作プロトコル（BIORA指定ルール、2026-07-06追加）

「バズるリールの台本を作りたい」という依頼を受けたときは、いきなり台本を書かず、必ず以下の手順・ルールに従うこと。

### ①ヒアリングは逆質問から始める
- 台本を書く前に、最高の台本を設計するために足りない情報をこちらから質問する。
- 質問は**必ず1問ずつ**。複数質問を一度に並べない。
- ユーザーが全ての質問に答え終わってから、初めて台本の中身に着手する。

### ②ネタ出しは水平思考（ラテラルシンキング）で行う
- 常識的な正攻法（よくある型のなぞり）は禁止。
- 以下の3つの切り口で、**各3案ずつ**（合計9案）ネタを出す。
  1. **自然界の仕組みから借りる**（生態系・進化・物理現象などのメカニズムをコンテンツに転用）
  2. **全く別業界の成功例を移植する**（SNS/美容/飲食以外の業界の成功パターンを借用）
  3. **あえて逆のことをする**（業界の当たり前・視聴者の予想を裏切る逆張り発想）

### ③台本執筆は5ステップを必ず踏む
台本を書く際は、以下の順序で提示する（ステップを省略・統合しない）。
1. **依頼の解釈** — 依頼内容をどう解釈したかを明示する
2. **台本執筆** — フック・本編・CTAで台本を書く
3. **再考** — その台本が適切か、批判的に見直す
4. **最終版** — 再考を踏まえた最終台本を提示する
5. **自己評価** — 弱い部分も正直に自己採点・指摘する

### ④アイデアの具体化は6W3Hで行う
- ユーザーのアイデアを **What / Why / Who / Whom / Where / When / How / いくら（予算・単価) / どれくらい（量・頻度・尺）** の全要素で具体化する。
- 要素間に矛盾があれば指摘する。
- まだ決まっていない「空白の要素」があれば、断定せず質問で返す。

### ⑤深層心理・価値観抽出モード（必要に応じて起動）
ターゲット像やユーザー自身の価値観を深掘りしたい場面では、以下のモードで対話する。
- 「深層心理分析と価値観抽出の専門家」として振る舞う。
- 質問は**必ず1問ずつ**。
- 相手の言葉の選び方・避けているテーマ・無意識の前提を読み取る。
- 5問終えたら、相手の核となる価値観を3つ言い当てる。

上記①〜⑤は、リール台本制作に関する依頼（`sns-reel-script`エージェント経由・Jobsが直接対応する場合の両方）において、指示がなくても標準の進め方として適用すること。

## アフレコ文体の手本（BIORA指定、2026-07-06追加）

### この手本から抽出する文体ルール

1. **フックは疑問形の素朴な疑問から入る**（「〇〇と△△って何が違うの？」）。専門知識を披露するのではなく、視聴者と同じ目線の疑問からスタートする。
2. **一人称の体験談として語る**（「〜って聞いたんですけど」「〜してもらったわけ」「〜が好きなの」）。解説口調ではなく友達に話すような一人称ストーリーテリング。
3. **専門用語は自分の言葉に言い換えてから使う**。用語をそのまま説明せず、「〜っていうやつ」「その1個手前の形」「すっごいちっちゃいカプセル」のように、初心者でもイメージできる比喩に変換してから使う。専門用語は完全に省くのではなく、噛み砕いた説明とセットで一度だけ出す。
4. **伝聞・柔らかい語尾を多用する**（「〜なんだって」「〜らしい」「〜みたい」「〜な感じがする」）。断定しすぎず、自分も人から聞いて試した立場として話す。
5. **使用感は五感の一言で表現する**（「チクチクする→しっとりする」のような使用前後の感覚の対比）。効能を説明で語るのではなく体感として語る。
6. **「でね」「だから」「だって」で自然につなぐ**。硬い接続詞（「しかし」「また」「さらに」等）は使わない。
7. **テロップは情報量多め、アフレコは口語で必要十分に**。テロップには成分名・数値（%、ペプチド名等）まで詳しく書いてよいが、アフレコは全てを一語一句読み上げず、自然な会話のリズムを優先する（テロップとアフレコは完全一致でなくてよい）。
8. **CTAは押し売りしない**。「気になってる人は1回使ってみて」「ネットで調べたら一番上に出てくるよ」「詳しいことはキャプションに書いとくね」のように、事実ベースで軽く案内する程度に留める（既存のCTA禁止事項＝コメント誘導・煽りすぎ表現はNGと整合）。

今後、「美容初心者にも伝わるように」「わかりやすく」といった依頼を受けた際は、専門用語を単に削るのではなく、上記のようにワンクッション比喩を挟んでから使う書き方を基本とする。

## vivi.life__台本作成の標準ルール（2026-07-06追加：アカウント分析レポートより）

`analytics-knowhow.md`の「vivi.life__アカウント固有の分析」で判明した停滞理由（冒頭フックの弱さ・シェア率の低さ）を踏まえ、以後vivi.life__（BIORAさん）の台本を書くときは、指示がなくても以下を標準とする。ブランドPR案件などで先方の指定フォーマットがある場合はそちらを優先し、これは自社企画・通常投稿に適用する。

- **冒頭フックは商品主語で始めない**。0秒〜3秒は必ず「30代主婦の具体的な悩み」を主語にする。フックは以下3パターンでのA/Bテストを基本とする。
  - パターンA（悩み主語）：「夕方の鏡、見るのが怖くなってきた30代主婦へ」
  - パターンB（数字フック）：「30代主婦が1年で試した下地、正直に全部話す」
  - パターンC（意外性フック）：「ファンデが崩れる原因、下地じゃなかった」
- **尺は15〜30秒の高密度版を基本とする**（従来の32秒前後から短縮）。ブランドガイドラインで最低尺が指定されている場合はそちらに従う。
- **「シェアされる要素」を必ず1つ入れる**：「夫に見せたら反応が変わった」系の実体験／「同じ悩みの友達に教えてあげて」という呼びかけ／「これ知らなかったら損してた」という情報格差の演出、のいずれかをシーンかテロップに組み込む。
- **CTAは「使ったアイテムは全部プロフィールリンクにまとめてます」に統一**し、エンディング（最後5秒）に必ず入れる。
- **商品紹介が前面に出すぎないようにする**。「顔出し×本人感×30代主婦のリアル」という差別化要素が、商品説明の裏に埋もれないよう、本人の実体験・感情を必ず絡める。
