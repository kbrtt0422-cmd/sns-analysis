# 組織図

## 現在（Phase 0.5：AIスクール事業 立ち上げ期）

```
┌──────────────────┐
│  取締役会          │
│  BIORA（オーナー）   │
└────────┬─────────┘
         │
┌────────▼─────────┐
│  CEO: Jobs (AI)   │
│  戦略・意思決定     │
├──────────────────┤
│                    │
▼                    ▼
┌──────────┐  ┌──────────────┐
│ CMO: Sara │  │ 営業: KAZU      │
│ (AI)      │  │ (人間・業務委託) │
│ マーケ統括 │  │ 無料相談・成約    │
└──────────┘  └──────────────┘
       │
       ▼
┌──────────┐
│ CTO: Ken  │
│ (AI)      │
│ 教材・添削設計│
└──────────┘
```

新規事業「非対面・添削特化型 SNSスクール」の体制：
- Jobs: 全体統括・意思決定
- Sara: 集客導線・申込フォーム・価格パッケージ設計
- Ken: カリキュラム・添削ルーブリック（AI添削下書き含む）設計
- KAZU: 無料相談（営業）担当。成約後はKen設計の教材・添削フローに引き渡す
- BIORA: 最小限の初期検証のみ対応し、型が固まり次第KAZUに引き継ぐ
