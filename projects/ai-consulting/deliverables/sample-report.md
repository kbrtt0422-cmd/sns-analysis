## 1. エグゼクティブサマリー

株式会社山田製作所様は、金属部品製造業として30年以上の実績をお持ちであり、高い技術力と安定した顧客基盤を有しておられます。一方で、**見積作成の属人化・長時間化**、**目視に依存した品質検査**、**ベテラン技術者のノウハウ継承**という3つの構造的な課題を抱えておられます。

本診断の結果、これら3つの課題それぞれに対し、**現在市場で入手可能なAIツール**を活用することで、大きな改善が見込めることが判明しました。

**期待される効果（年間合計）：**

- 見積作成時間：**年間約960時間の削減**（現状の60%短縮）
- 品質検査の不良見逃し率：**現状比80%低減**
- ナレッジ共有による新人教育期間：**従来の半分に短縮**

特筆すべきは、いずれも「数千万円の大型投資」ではなく、**月額数万円〜十数万円のクラウドサービスの組み合わせ**で実現可能であるという点です。中小企業にとって現実的な範囲の投資で、大企業と同等のAI活用が可能な時代が到来しています。

以下、詳細をご報告いたします。

### 2.2 ヒアリングで把握した主要課題

#### 課題1：見積作成に時間がかかる

- 月間の見積件数：約80件
- 1件あたりの平均作成時間：**約2.5時間**（複雑な案件では半日以上）
- 見積を作成できるのは営業部長と社長の**2名のみ**
- 過去の類似案件を探すのに毎回時間がかかる
- 見積の精度にばらつきがあり、利益率の低い案件を受注してしまうケースがある

#### 課題2：品質検査が目視頼み

- 検査員3名が目視で外観検査を実施
- 1日あたり約500個の部品を検査
- 疲労による見逃し率：推定**2〜3%**（社内調査）
- 不良品の顧客流出が年に数回発生し、クレーム対応コストが発生
- 検査基準が検査員の経験に依存している

#### 課題3：ベテランのノウハウが属人化

- 加工条件の設定、材料選定、トラブル対応は**ベテラン3名に集中**
- マニュアルはあるが「勘所」が文書化されていない
- 若手が一人前になるまで**5〜7年**かかる
- ベテラン3名のうち2名が5年以内に定年予定

## 3. AI活用ポイント

### 3.1 見積作成のAI支援

| 項目 | 内容 |
|------|------|
| 対象業務 | 見積書の作成（材料費・加工費・工数の算出） |
| 導入難易度 | ★★☆☆☆（低〜中） |
| 初期費用 | 約15万円（設定・データ整備） |
| 月額費用 | 約3万円 |
| 投資回収 | 約3ヶ月 |

**現状の課題：**
見積1件あたり平均2.5時間、月間80件で合計200時間。営業部長と社長の2名に集中しており、本来の営業活動や経営判断に割く時間が圧迫されている。

**AI活用の具体策：**

1. **過去見積データのAI検索・参照システム**
   - 過去3年分の見積データ（約2,800件）をデータベース化
   - 図面情報（材質・形状・寸法・公差）をキーに類似案件をAIが自動検索
   - 推奨ツール：**Microsoft Copilot for Microsoft 365**（月額4,497円/ユーザー）
     - Excel上で過去データを参照しながら見積を自動生成
     - 「この形状・材質・数量に近い過去案件を3件提示して」と自然言語で指示可能
   - 補助ツール：**ChatGPT Team**（月額約4,000円/ユーザー）
     - 見積の妥当性チェック、顧客向け説明文の作成

2. **見積精度の向上**
   - 過去の見積と実績（実際の原価）を突合し、乖離パターンをAIが学習
   - 利益率が低くなりがちな案件パターンを事前にアラート

**期待効果：**
- 見積作成時間：2.5時間 → **1.0時間**（60%短縮）
- 年間削減時間：**約960時間**（200時間/月 × 12ヶ月 × 40%の時間がそのまま空く計算）
- 金額換算：約**480万円/年**相当（時間単価5,000円で計算）
- 見積精度の向上による利益率改善：推定**0.5〜1.0%ポイント**

### 3.2 AI画像検査の導入

| 項目 | 内容 |
|------|------|
| 対象業務 | 金属部品の外観検査（キズ・打痕・バリ・寸法異常） |
| 導入難易度 | ★★★☆☆（中） |
| 初期費用 | 約80〜120万円（カメラ・照明・設定費込み） |
| 月額費用 | 約5万円 |
| 投資回収 | 約8〜12ヶ月 |

**現状の課題：**
検査員3名で1日500個を目視検査。疲労による見逃し率2〜3%で、年間数回の顧客クレームが発生。1件あたりのクレーム対応コスト（選別・再検査・報告書作成）は推定20〜50万円。

**AI活用の具体策：**

1. **AI外観検査システムの導入**
   - 推奨ツール：**MENOU（メノウ）**
     - 中小製造業向けに特化したAI外観検査プラットフォーム
     - プログラミング不要で検査モデルを構築可能
     - 初期費用：80万円〜、月額：5万円〜
   - 代替候補：**HACARUS（ハカルス）** 少量データでも学習可能なAI検査
   - 必要機材：産業用カメラ（約20万円）、LED照明（約5万円）

2. **導入ステップ**
   - 最も検査量が多い製品（A製品群）から開始
   - 最初の1ヶ月は目視検査と並行運用し、AI精度を検証
   - OK品/NG品の画像を各200枚程度撮影すれば初期モデル構築可能

**期待効果：**
- 不良見逃し率：2〜3% → **0.3〜0.5%**（80%以上低減）
- 検査速度：1個あたり15秒 → **3秒**（5倍高速化）
- クレーム対応コスト削減：年間**100〜200万円**
- 検査員の負荷軽減（検査員3名 → 2名体制で運用可能、1名を他業務に配置転換）

### 3.3 ベテランノウハウのAIナレッジ化

| 項目 | 内容 |
|------|------|
| 対象業務 | 加工条件設定、材料選定、トラブルシューティング |
| 導入難易度 | ★★☆☆☆（低〜中） |
| 初期費用 | 約20万円（ナレッジ整備支援） |
| 月額費用 | 約2万円 |
| 投資回収 | 約6ヶ月（教育コスト削減として） |

**現状の課題：**
ベテラン3名に技術ノウハウが集中。新人教育に5〜7年かかる。ベテラン2名が5年以内に定年予定で、技術継承が経営リスクになっている。

**AI活用の具体策：**

1. **社内AIチャットボット（ナレッジベース）の構築**
   - 推奨ツール：**Dify**（オープンソース / クラウド版月額約8,000円〜）
     - 社内文書・マニュアル・過去のトラブル報告書をアップロード
     - 「SUS304を旋削するときの推奨切削速度は？」「ビビリが発生したときの対処法は？」等の質問に即座に回答
   - 補助ツール：**Notion AI**（月額約1,500円/ユーザー）
     - ベテランへのインタビュー内容を構造化して蓄積

2. **ナレッジ収集の仕組み化**
   - ベテランに週1回30分の「技術メモ」作成を依頼（音声入力→AI文字起こし→構造化）
   - 音声入力ツール：**CLOVA Note**（無料）または**Notta**（月額約2,000円）
   - トラブル発生時の対応記録をテンプレート化し、自動的にナレッジベースに蓄積

**期待効果：**
- 新人教育期間：5〜7年 → **2.5〜3.5年**（約半分に短縮）
- ベテラン不在時の対応力向上（問い合わせの**70%**をAIが即時回答）
- 技術ノウハウの永続的な資産化（退職リスクの大幅低減）
