# 業種別AI活用パターン集

中小企業がすぐに取り組めるAI活用例を、5つの業種ごとに整理しました。
各パターンは「導入コスト月額10万円以下」を基本とし、専門的なIT知識がなくても導入可能なものを厳選しています。

---

## 1. 製造業

### 1-1. AI外観検査による品質向上

| 項目 | 内容 |
|------|------|
| 活用名 | AI画像認識による外観検査自動化 |
| 課題（Before） | 目視検査に依存し、検査員の疲労により不良見逃し率が2〜3%。ベテラン検査員の退職で品質維持が困難に。 |
| AI活用内容（After） | 産業用カメラで撮影した製品画像をAIが判定。キズ・打痕・バリなどを自動検出し、OK/NGを瞬時に分類。人間は最終確認のみ。 |
| 推奨ツール | MENOU（メノウ）、HACARUS（ハカルス）、Amazon Lookout for Vision |
| 導入コスト目安 | 初期費用80〜150万円、月額5〜10万円 |
| 期待効果 | 不良見逃し率80%低減、検査速度5倍向上、検査人員1名削減可能 |
