# 明日から使える！AI活用ハンズオン研修

## 研修概要

| 項目 | 内容 |
|------|------|
| 研修名 | 明日から使える！AI活用ハンズオン研修 |
| 対象 | AI初心者の中小企業社員（役職不問） |
| 前提知識 | パソコンの基本操作、メール・Excelが使えるレベル |
| 定員 | 5〜15名 |
| 時間 | 4時間（午前の部 9:00〜13:00 / 午後の部 13:30〜17:30） |
| 形式 | 対面（会議室）またはオンライン（Zoom） |
| 研修ゴール | 研修後にChatGPT/Claudeを自分の業務で使えるようになる |

## 到達目標

研修修了時に参加者が以下のことができるようになる：

1. ChatGPT / Claudeに適切な指示（プロンプト）を出して、業務に使える回答を得られる
2. 自分の業務の中で「AIに任せられる作業」を3つ以上特定できる
3. AIに渡してはいけない情報（機密情報・個人情報）を判断できる
4. 翌営業日から実際にAIを業務で使い始められる

### セクション1：AIって何？ 怖くない！（9:00〜9:40）40分

#### 9:00〜9:10 オープニング・自己紹介（10分）

- 講師自己紹介
- 参加者自己紹介（名前・部署・AIへの期待/不安を一言）
- 研修のゴールとルールの説明
  - 「わからない」は恥ずかしくない。質問大歓迎
  - 完璧を目指さない。「70点で十分」の精神

#### 9:10〜9:30 AIの基本を理解する（20分）

**講義内容：**
- AIとは何か（難しい定義は不要。「めちゃくちゃ賢い文章作成マシン」でOK）
- ChatGPT / Claude / Gemini の違い（車で例える：トヨタ・ホンダ・日産みたいなもの）
- AIにできること・できないことの整理
  - できる：文章作成、要約、翻訳、アイデア出し、データ分析の補助
  - できない：事実の100%保証、最新情報、感情の理解、自社の未公開情報の把握
- 中小企業のAI活用事例3選（実際の成功事例を紹介）

**スライドで見せるもの：**
- ビフォーアフターの具体例（「メール作成30分→3分」等）
- AI活用企業の数字（業務時間XX%削減等の実績データ）

#### 9:30〜9:40 セキュリティの基本（10分）

**必ず伝える内容：**
- AIに入力してはいけない情報
  - 顧客の個人情報（氏名、住所、電話番号、メールアドレス）
  - 自社の機密情報（未公開の財務数値、戦略文書）
  - パスワード、アカウント情報
  - 取引先の機密情報
- 安全な使い方のルール
  - 有料プラン（Team/Business）は学習に使われない
  - 不安なら「固有名詞を仮名に変えて入力する」テクニック
- 社内AI利用ガイドラインの確認（事前に作成しておく）

### セクション2：まずは触ってみよう！（9:40〜10:40）60分

#### 9:40〜9:55 アカウント設定・初めての対話（15分）

**ハンズオン：**
1. ChatGPT（またはClaude）にログイン
2. 最初のメッセージを送る：「こんにちは。私は〇〇会社の〇〇部で働いています。今日からAIの使い方を学びます。」
3. 返答を確認して「AIと会話する」体験をする
4. 簡単な質問を3つ投げてみる
   - 「今日のランチにおすすめのメニューを3つ教えて」
   - 「ビジネスメールの書き方のコツを教えて」
   - 「〇〇業界の最近のトレンドを教えて」

#### 9:55〜10:25 プロンプトの基本（30分）

**講義（10分）：**
- プロンプトとは「AIへの指示文」
- 良いプロンプトの4要素（STAR法）：
  - **S**ituation（状況）：あなたは何者か
  - **T**ask（タスク）：何をしてほしいか
  - **A**udience（対象）：誰向けか
  - **R**equirement（要件）：形式・長さ・トーンの指定

**ハンズオン（20分）：**

**課題1：悪いプロンプト vs 良いプロンプト**

悪い例：
```
メールを書いて
```

良い例：
```
あなたは中小企業の営業担当です。
以下の内容で取引先へのお礼メールを作成してください。

【状況】先日、A社の田中部長と商談を行い、前向きな回答をいただいた
【トーン】丁寧だが堅すぎない。親しみを感じる文体
【長さ】200字程度
【含める内容】
- 商談のお礼
- 提案資料の送付案内
- 次回打ち合わせの日程調整依頼
```

参加者全員が「良いプロンプト」を実際に入力し、結果を比較する。

**課題2：自分の業務でプロンプトを作る**
- 各自の業務で「こういうメールをよく書く」「こういう文書を作る」を1つ選ぶ
- STAR法に沿ってプロンプトを作成
- AIに投げて結果を確認
- 隣の人と結果を見せ合う

#### 10:25〜10:40 プロンプトの応用テクニック（15分）

**講義＋デモ：**
- 「〇〇として振る舞って」（ロール設定）
- 「ステップバイステップで考えて」（思考の誘導）
- 「以下のフォーマットで出力して」（出力制御）
- 「まず3つの案を出して、その中から最も良いものを選んで」（段階的指示）
- やり直しの仕方：「もう少しカジュアルに」「箇条書きに変えて」「具体例を追加して」

### セクション3：業務別AI活用ハンズオン（10:50〜12:10）80分

#### 10:50〜11:20 文書作成・メール作成（30分）

**ハンズオン課題：**

**課題3：議事録の要約**
- 講師が用意した「散らかった会議メモ」をAIに渡す
- 「以下の会議メモを、決定事項・To-Do・次回議題の3つに整理してください」
- 出力結果を確認し、修正指示を出す練習

**課題4：報告書のドラフト作成**
- 「先月の売上報告書のドラフトを作って」という課題
- 必要な情報（数字・背景）を入力して、報告書を生成
- 「上司に提出できるレベル」に仕上げるための修正を練習

**課題5：難しいメールへの返信**
- クレームメール、断りメール、依頼メールなど「書きにくいメール」のテンプレート
- 参加者の実際の業務で「書くのに悩むメール」を題材にする

#### 11:20〜11:50 データ分析・Excel活用（30分）

**ハンズオン課題：**

**課題6：売上データの分析**
- 講師が用意したサンプルCSVデータ（架空の売上データ）をChatGPTにアップロード
- 「このデータの傾向を分析して、グラフを作成してください」
- 「売上が落ちている商品カテゴリとその原因仮説を教えて」
- グラフの出力結果を確認

**課題7：Excel関数・マクロの相談**
- 「こういう計算をしたいがExcel関数がわからない」をAIに質問
- VLOOKUP、IF関数、ピボットテーブルの作り方をAIに聞く体験
- 実際のExcelファイルで試す

#### 11:50〜12:10 アイデア出し・企画立案（20分）

**ハンズオン課題：**

**課題8：ブレインストーミング相手としてのAI**
- 「来月の販促キャンペーンのアイデアを10個出して」
- 「その中から実現可能性とインパクトで上位3つを選んで、理由も教えて」
- 「1位のアイデアについて、実施計画の骨子を作って」

**課題9：自社業務の改善案**
- 各自の業務で「困っていること」をAIに相談
- AIの提案を基に、翌日から試せるアクションを1つ決める

| 項目 | 内容 |

| 項目 | 内容 |
|------|------|
| 形式 | オンライン（Zoom） |
| 時間 | 45分 |
| 内容 | 研修前後の業務時間変化の測定 / 継続的に使えているかの確認 / 次のステップ（応用研修）の案内 |

- **プロンプトライブラリ**（共有ドキュメント）：研修参加者が使えるプロンプト集を継続的に更新

## 講師向け注意事項

1. **ペースは参加者に合わせる**：予定通り進まなくても焦らない。セクション3の時間配分で調整。
2. **否定しない**：「そんなこともわからないの？」は絶対NG。「良い質問ですね」を口癖にする。
3. **実体験を交える**：「私も最初はこう使って失敗しました」というエピソードが親近感を生む。
4. **画面を見せながら進める**：「今から私がやるのを見ていてください。その後、同じことをやってみましょう」の流れ。
5. **時間に余裕を持つ**：初心者はログインだけで10分かかることもある。焦らず待つ。
