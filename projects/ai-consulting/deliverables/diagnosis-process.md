# AI活用診断プロセス 標準手順書

## 概要

本手順書は、中小企業向けAI活用診断サービスの全工程を標準化したものです。
診断担当者は本手順書に沿って業務を遂行し、一定品質のサービスを提供してください。

**診断の全体フロー：**

```
[1. ヒアリング準備] → [2. ヒアリング実施] → [3. 分析] → [4. レポート作成] → [5. 報告]
     1〜2日            1〜2時間           2〜3日        2〜3日          1時間
                                                              合計：約7〜10営業日
```

---

## 工程1：ヒアリング準備（所要時間：1〜2日）

### 1.1 事前情報の収集

診断対象企業について、以下の情報を事前に収集する。

**公開情報から収集するもの：**
- [ ] 企業Webサイトの確認（事業内容、製品・サービス、会社概要）
- [ ] 業種・業界の基本情報（市場規模、業界トレンド、競合状況）
- [ ] SNS・口コミサイトの確認（Googleマップ口コミ、SNSアカウント等）
- [ ] 過去のニュース・プレスリリース

**申込フォームから取得済みの情報：**
- [ ] 企業名、業種、従業員数、年商規模
- [ ] 担当者の氏名・役職・連絡先
- [ ] 現在のIT環境（利用中のソフトウェア・クラウドサービス）
- [ ] AIに期待すること（自由記述）

### 1.2 ヒアリングシートの準備

以下のヒアリングシートを事前に準備し、企業に合わせてカスタマイズする。

**基本ヒアリング項目（全業種共通）：**

```
【企業概要】
Q1. 事業内容を改めて教えてください
Q2. 主要な製品・サービスは何ですか
Q3. 主要な顧客層はどのような方々ですか
Q4. 従業員の年齢構成・部門構成を教えてください

【業務の現状】
Q5. 1日の業務の流れを教えてください（主要な業務フロー）
Q6. 最も時間がかかっている業務は何ですか
Q7. 最もミスが多い・品質にばらつきがある業務は何ですか
Q8. 「この人がいないと回らない」という業務はありますか（属人化）
Q9. 繰り返し発生している定型業務はありますか

【IT環境】
Q10. 現在使っているソフトウェア・クラウドサービスを教えてください
Q11. 社内のIT担当者はいますか
Q12. 過去にIT導入で失敗した経験はありますか
Q13. 社内のインターネット環境はどうですか（速度・安定性）

【AI・DXへの期待】
Q14. AIやDXに期待することは何ですか
Q15. AI活用で不安に思うことはありますか
Q16. 投資可能な予算感はどの程度ですか（月額ベース）
Q17. いつまでに効果を出したいですか

【経営課題】
Q18. 現在の経営上の最大の課題は何ですか
Q19. 3年後にどのような会社になっていたいですか
Q20. 人材採用・育成で困っていることはありますか
```

**業種別追加質問：**

製造業の場合：
- 品質管理の方法（目視？計測器？）
- 設備の稼働状況・メンテナンス頻度
- 見積・積算のプロセス
- 在庫管理の方法

小売業の場合：
- EC展開の有無・比率
- 顧客管理の方法（CRM等）
- 在庫管理・発注の方法
- SNS・マーケティングの状況

サービス業の場合：
- 予約管理の方法
- 顧客満足度の測定方法
- リピート率
- スタッフのシフト管理方法

建設業の場合：
- 積算・見積の方法
- 工程管理の方法
- 安全管理の体制
- 図面管理の方法

士業の場合：
- 顧問先の数・管理方法
- 定型業務の割合
- リサーチ業務の頻度
- 顧問先への報告方法

### 1.3 ヒアリング日程の調整

- ヒアリング対象者：**経営者（社長）+ 現場責任者1〜2名**が理想
- 所要時間：**1.5〜2時間**
- 場所：顧客企業を訪問（できれば現場を見せてもらう）
- オンラインの場合：Zoomで実施し、録画許可を取得

### 1.4 事前送付物

ヒアリングの2〜3営業日前に以下を送付：

- [ ] ヒアリングの目的・進め方の説明文
- [ ] 事前にご記入いただく簡易アンケート（Q1〜Q6程度）
- [ ] 当日の参加者・所要時間の確認

## 工程2：ヒアリング実施（所要時間：1.5〜2時間）

### 2.1 ヒアリング当日の流れ

| 時間 | 内容 | 備考 |
|------|------|------|
| 0:00〜0:10 | 挨拶・自己紹介・本日の流れ説明 | アイスブレイクを忘れずに |
| 0:10〜0:30 | 企業概要・事業内容の確認 | 事前情報と突き合わせ |
| 0:30〜1:00 | 業務の現状ヒアリング（Q5〜Q9） | ここが最重要パート |
| 1:00〜1:15 | IT環境の確認（Q10〜Q13） | 実際の画面を見せてもらう |
| 1:15〜1:30 | AI・DXへの期待と課題（Q14〜Q17） | 予算感は慎重に確認 |
| 1:30〜1:45 | 経営課題の深堀り（Q18〜Q20） | 経営者の本音を引き出す |
| 1:45〜2:00 | 現場見学（可能な場合）/まとめ | 百聞は一見にしかず |

### 2.2 ヒアリング時のポイント

**必ず守ること：**
- 録音の許可を冒頭で取得する（議事録作成のため）
- 「AIを売り込む」のではなく「課題を理解する」姿勢
- 専門用語を避ける。相手の言葉で話す
- メモは要点のみ。録音があるので書くことに集中しすぎない

**深堀りのコツ：**
- 「それは具体的にどういうことですか？」（抽象→具体）
- 「それはどのくらいの頻度で起きますか？」（定性→定量）
- 「その業務は誰が、何時間くらいかけていますか？」（人・時間の把握）
- 「もしその問題が解決したら、何が一番変わりますか？」（効果の仮説）
- 「過去に改善を試みたことはありますか？」（過去の取り組みの確認）

**避けるべきこと：**
- ヒアリング中に解決策を提示しない（分析後にまとめて提案する）
- 「AIで解決できます！」と安易に断言しない
- 技術的な話に深入りしない（経営者は興味がない）
- 他社の機密情報を口にしない

### 2.3 ヒアリング後の即時対応

ヒアリング終了後、**当日中**に以下を実施：

- [ ] ヒアリング内容の文字起こし（Notta等で自動化）
- [ ] お礼メールの送信（翌営業日の午前中まで）
- [ ] ヒアリングメモの整理（30分以内に要点をまとめる）
- [ ] 第一印象の課題仮説を3つ書き出す

## 工程3：分析（所要時間：2〜3日）

### 3.1 業務フローの整理

ヒアリング内容を基に、主要な業務フローを図式化する。

**作成する資料：**
- 業務フロー図（全体概要）
- 各業務の所要時間・頻度・担当者の一覧表
- 課題マッピング（どの業務にどの課題があるか）

### 3.2 AI活用ポイントの特定

以下の基準でAI活用ポイントを評価し、優先順位をつける。

**評価基準（各5点満点、合計20点で評価）：**

| 基準 | 観点 |
|------|------|
| 効果の大きさ | 時間削減・コスト削減・品質向上のインパクトはどの程度か |
| 導入のしやすさ | 技術的な難易度、既存業務への影響の小ささ |
| 投資回収の速さ | 何ヶ月で元が取れるか |
| 経営者の関心度 | ヒアリングで経営者が強い関心を示したか |

**評価結果の例：**

| AI活用ポイント | 効果 | 容易さ | 回収 | 関心 | 合計 |
|----------------|------|--------|------|------|------|
| 見積AI支援 | 5 | 4 | 5 | 5 | 19 |
| 外観検査AI | 5 | 3 | 4 | 4 | 16 |
| ナレッジAI化 | 4 | 4 | 3 | 5 | 16 |

**上位3つ**をレポートに記載する。

### 3.3 ツール選定

各AI活用ポイントについて、推奨ツールを選定する。

**選定基準：**
- 中小企業の予算感に合っているか（月額10万円以下が目安）
- 日本語対応は十分か
- サポート体制は充実しているか
- 導入実績は十分か
- セキュリティは確保されているか

**ツール選定シート：**

| 項目 | ツールA | ツールB | ツールC |
|------|---------|---------|---------|
| ツール名 | | | |
| 月額費用 | | | |
| 初期費用 | | | |
| 日本語対応 | ◎/○/△ | | |
| サポート | ◎/○/△ | | |
| 導入実績 | ◎/○/△ | | |
| 総合評価 | | | |

### 3.4 ROI算出

各施策について、以下のフォーマットでROIを算出する。

```
【施策名】：___________________

■ コスト
- 初期費用：___万円
- 月額費用：___万円
- 年間合計：___万円

■ 効果（年間）
- 時間削減：___時間 × 時間単価___円 = ___万円
- コスト削減：___万円
- 売上増加効果：___万円（推定）
- 年間効果合計：___万円

■ ROI
- 投資回収期間：___ヶ月
- 年間ROI：___%
```

### 3.5 ロードマップの作成

3つのフェーズでロードマップを作成する。

- **Phase 1（1〜2ヶ月目）**：最も効果が出やすく、導入が簡単なもの
- **Phase 2（3〜6ヶ月目）**：本格的な導入。投資が必要なもの
- **Phase 3（7〜12ヶ月目）**：発展・定着。効果の最大化

## 工程4：レポート作成（所要時間：2〜3日）

### 4.1 レポートの構成

以下の構成でレポートを作成する。

1. **エグゼクティブサマリー**（1ページ）
   - 経営者が最初に読む部分。結論を先に書く
   - 期待効果の数値を明確に記載

2. **業務概要の整理**（1〜2ページ）
   - 企業プロフィール
   - 業務フロー図
   - 課題の整理

3. **AI活用ポイント**（3〜4ページ）
   - 3つの提案（各1ページ程度）
   - 具体的なツール名と価格
   - 期待効果の数値

4. **導入ロードマップ**（1〜2ページ）
   - Phase 1/2/3の詳細
   - 全体のタイムライン図

5. **有料サービスのご提案**（1ページ）
   - 3プランの提示
   - 推奨プランとその理由

### 4.2 レポート作成のルール

**文章のトーン：**
- 経営者が読むことを前提に、平易な言葉で書く
- 専門用語を使う場合は必ず説明を添える
- 「御社」ではなく「貴社」を使用（文書のため）
- 箇条書きと表を多用し、読みやすさを重視

**数値の扱い：**
- 効果はすべて**年間換算**で記載
- 時間単価は**5,000円/時間**を標準とする（顧客と合意した場合は変更可）
- ROIは控えめに算出する（過大な期待を持たせない）
- 幅のある推定は「200〜300万円」のように記載

**品質チェックリスト（レポート提出前）：**
- [ ] 誤字脱字がないか
- [ ] 企業名・担当者名が正しいか
- [ ] 数値に計算ミスがないか
- [ ] ツールの価格情報が最新か
- [ ] エグゼクティブサマリーだけ読んでも概要がわかるか
- [ ] 提案内容が顧客の予算感に合っているか
- [ ] 専門用語に説明が添えられているか
- [ ] ロードマップに無理がないか
- [ ] 有料サービスの提案が押し売りになっていないか
- [ ] PDFに変換して体裁が崩れていないか

### 4.3 内部レビュー

レポート完成後、提出前に内部レビューを実施する。

**レビュー観点：**
- 提案内容の妥当性（技術的に実現可能か）
- ROI算出の妥当性（数値が現実的か）
- 有料サービスへの導線が自然か
- 全体の読みやすさ・わかりやすさ

## 工程5：報告（所要時間：1時間）

### 5.1 報告会の準備

- 報告日時の調整（レポート完成後、3営業日以内に実施）
- 参加者の確認（ヒアリング参加者 + 意思決定者）
- レポートの事前送付（**報告会の前日まで**に送付。当日初見は避ける）
- プレゼン資料の準備（レポートのサマリー版。スライド10枚程度）

### 5.2 報告会の進行

| 時間 | 内容 | 備考 |
|------|------|------|
| 0:00〜0:05 | 挨拶・本日の流れ | |
| 0:05〜0:15 | エグゼクティブサマリーの説明 | ここで全体像を伝える |
| 0:15〜0:35 | AI活用ポイント3つの詳細説明 | デモがあると効果的 |
| 0:35〜0:45 | ロードマップの説明 | |
| 0:45〜0:55 | 質疑応答 | |
| 0:55〜1:00 | 有料サービスの案内・次のステップ | 押し売りにならないよう注意 |

### 5.3 報告時のポイント

- レポートを「読み上げる」のではなく「対話する」
- 経営者の反応を見ながらペースを調整
- 質問は歓迎。「わからない」は正直に伝え、後日回答する
- 有料サービスの説明は**聞かれたら詳しく、聞かれなければ簡潔に**
- 「いつまでに判断いただきたい」とは言わない。「ご検討ください」で終える

### 5.4 報告後のフォロー

- [ ] 報告会のお礼メール送信（翌営業日の午前中まで）
- [ ] 質疑で回答できなかった事項への追加回答（3営業日以内）
- [ ] 1週間後にフォローアップ連絡（「ご検討状況はいかがですか？」）
- [ ] 2週間後に再度フォロー（反応がない場合は「追加のご質問があれば」程度で）
- [ ] 1ヶ月後に最終フォロー（「ご参考情報として業界のAI活用事例をお送りします」）

## よくある質問と回答例

### Q1：「AIって本当に中小企業でも使えるの？大企業向けでしょ？」

**回答例：**
「むしろ今は中小企業にこそチャンスがあると考えています。なぜなら、以前は数千万円かかったAIが、月額数千円〜数万円で使えるようになったからです。大企業は社内調整に時間がかかりますが、中小企業は社長の判断で翌日から導入できます。この意思決定の速さが最大の武器です。実際に、当社がご支援した製造業の企業様では、ChatGPTの導入だけで月間40時間の業務時間を削減されました。」

### Q2：「AIに仕事を奪われるんじゃないの？社員が不安がっている」

**回答例：**
「AIは人の仕事を『奪う』のではなく、『退屈な作業から解放する』ものです。例えば、議事録作成に30分かけていた時間がAIで3分になったら、その27分を顧客対応や企画立案に使えます。AIは『部下に任せたいけど人がいない』という定型業務を代わりにやってくれるアシスタントだとお考えください。実際、AI導入で人員削減した企業は少数で、多くは『人にしかできない仕事に集中できるようになった』と仰います。」

### Q3：「情報漏洩が心配。うちのデータをAIに入れて大丈夫？」

**回答例：**
「非常に重要なご懸念です。まず、ChatGPTやClaudeの有料ビジネスプランでは、入力されたデータがAIの学習に使われないことが契約で明記されています。さらに、どのデータをAIに入れて良いか・いけないかのガイドラインを一緒に作成します。例えば、顧客の個人情報はAIに入れない、社内の数値データは匿名化してから入れる、といったルールです。適切なルールがあれば、安全にAIを活用できます。」

### Q4：「ITに詳しい人がいないんだけど、それでも導入できる？」

**回答例：**
「はい、大丈夫です。私たちのサービスは、まさにIT専任者がいない企業様向けに設計しています。ChatGPTの使い方は、LINEでメッセージを送るのとほとんど同じです。実際の研修では、スマートフォンが使える方なら全員が4時間で使えるようになっています。導入時のツール設定は当社が代行しますし、導入後も月次のサポートで疑問にお答えします。」

### Q5：「効果が出なかったらどうするの？」

**回答例：**
「まず、本日の無料診断の中で、効果が見込める施策のみをご提案しています。その上で、Phase 1では最も確実に効果が出る施策から始めますので、2ヶ月目には効果を実感いただけるはずです。万が一期待した効果が出ない場合は、原因を分析して別のアプローチをご提案します。また、有料サービスについては、効果に納得いただけなかった場合の途中解約も可能です。」

### Q6：「費用対効果はどのくらい？」

**回答例：**
「業種や課題によりますが、一般的な中小企業様では、月額3〜10万円程度のAIツール投資で、月間30〜80時間の業務時間削減を実現しています。時間単価5,000円で計算すると、月15〜40万円相当の効果です。ROIは300〜500%程度になることが多いです。今回の診断レポートでは、貴社の具体的な数値を基にROIを算出してお示しします。」

### Q7：「同業他社はもうAIを使っているの？」

**回答例：**
「中小企業のAI活用はまだ始まったばかりで、本格的に取り組んでいる企業は全体の10〜15%程度です。つまり、今始めれば同業他社に対して先行者優位を得られるタイミングです。逆に、2〜3年後にはAI活用が当たり前になり、使っていない企業が競争力で劣後する可能性があります。早めに始めて、ノウハウを蓄積されることをおすすめします。」

### Q8：「無料診断の後、必ず有料契約しないといけないの？」

**回答例：**
「いいえ、まったくそのようなことはありません。無料診断レポートは、それ自体で価値のある情報をご提供しています。レポートの内容を基にご自身で導入を進めていただくことも可能です。有料サービスは、『自社だけでは難しい』『専門家に伴走してほしい』という場合にご利用いただくものです。押し売りは一切いたしませんので、ご安心ください。」
