## 前提：分析の指標定義

本レポートで使用する指標の定義（analytics-knowhow.md 準拠）：

- **保存率** = 保存数 ÷ いいね数 × 100（%）／目安：良い＝150〜200%以上、普通＝80〜100%、悪い＝50%以下
- **フォロー率（リール）** = 新規フォロワー数 ÷ リーチ数 × 100（%）／目安：良い＝0.4%以上、普通＝0.3%、悪い＝0.2%以下
- **アクセス率（フィード）** = プロフィールアクセス数 ÷ リーチ数 × 100（%）／目安：良い＝5%以上
- **競合分析の優先対象**：50〜100投稿・フォロワー5,000人以上の直近成長アカウント（古いアカウントは優先度低）

### 1-1. @runa_freelance.life

**概要・推定プロフィール（WebSearch調査＋ジャンル類推）**

「フリーランス×生き方・働き方」をテーマにしたアカウントと推定。ジャンル名（freelance.life）から、フリーランスとしての日常・収入・働き方ノウハウを発信するタイプと見られる。SNS運用代行スクール受講者またはSNSフリーランス発信者の典型パターン。

> **注意**：直接のInstagramインサイトデータは取得不可のため、以下はジャンル分析・パターン推定に基づく仮説。

**推定フォーマット・投稿傾向**
- テキスト＋文字重視リール（ノウハウ提供型）が中心
- 「フリーランスになった経緯」「月収公開」「副業始め方」などストーリー性と実績数字の組み合わせが多いジャンル
- 顔出しあり・なし混在型が多い中、このアカウントはプロフィール名の設計（.lifeという生活感のある命名）からライフスタイル系との掛け合わせを狙っている可能性

**伸びている構成パターン（類推）**
- 冒頭：「会社員から3ヶ月でフリーランスになった話」「月収○万円達成したリアル」等の数字＋体験談型

- 末尾：「続きはこちら」「プロフィールから確認」等のCTA

**キャプションスタイル（推定）**
- 短め〜中程度。最初の一文にフォロー推奨ワードを入れ、本文は動画の補足。ハッシュタグは10〜15個程度（このジャンルの標準）

**Tiaful参考ポイント**

**概要・推定プロフィール**

- 高価格スクール（数十万円台）を販売する際のコンテンツ設計・信頼構築の方法
- 英語コーチング系は月商740万円達成事例（フォロワー2.5万人）が出ており、フォロワー数に対する収益効率が非常に高いジャンル

**推定フォーマット・投稿傾向**
- リール：英語学習tips（実用型）+ 自己開示（学習継続の共感型）の2軸

- 受講生の成果（案件獲得・月収○万）をストーリーズで定期的に出す導線は必須
- リール→プロフィール→ストーリー→DM→無料相談の導線はTiafulの既定導線と完全一致

**フォロワー規模感（業界参考値）**

## 2. ジャンル全体トレンド分析

### 2-1. このジャンルで伸びている投稿テーマ TOP5

analytics-knowhow「④競合分析の視点」および2026年最新WebSearch情報を統合した判断：

| 順位 | テーマ | 理由・根拠 |
|------|--------|-----------|
| 1 | 「未経験から〇ヶ月で月収○万達成した話」 | 数字＋タイムライン＋ビフォーアフター。保存率・コメント率ともに高い。真似度高い企画パターン |
| 2 | 「SNS運用代行の始め方・案件の取り方」 | 実用ノウハウ型。保存率重視（目安：150%以上を狙いやすい）。初心者の「知りたい」に直結 |
| 3 | 「在宅でできる副業〇選（SNS運用代行編）」 | ジャンル認知拡大に効く。「副業」「在宅」ワードが検索流入・発見欄流入に強い |
| 4 | 「フリーランスになって変わった/後悔したこと」 | 共感・体験談型。コメント誘発が高く、保存率が低くてもバズに乗るコメント主導型パターン |
| 5 | 「案件の単価を上げた方法・交渉術」 | 既存層（すでに副業中の人）の悩みに刺さる。保存率が高くなりやすいノウハウ型 |

### 2-2. 伸びているリールの共通パターン

**冒頭（最初の3秒）**

- 数字から入るパターン：「3ヶ月で月30万」「未経験から120日で案件獲得」
- 悩み代弁から入るパターン：「副業始めたいけど何のスキルを身につければいいか分からない」
- 禁止/警告から入るパターン：「このやり方、間違ってます」「これをやるとSNS運用代行は稼げません」

→ 共通点：冒頭でターゲット（副業したい30代女性）が「自分のことを言われている」と感じる一文

**テンポ**

- 教育系：60〜90秒が最適（2026年算出基準）。ノウハウを1点〜3点に絞って深く解説
- 共感・体験談系：30〜60秒。テンポ早め、感情の変化を見せる
- 15秒以下：リプレイ率が1.8倍高い。最初はショートリールでリーチを取る戦略も有効

**文字量**

- テロップのみ（顔出しなし）の場合：1カットに15文字以内、単語区切りで大きめフォント
- ナレーション（音声）あり：テロップは補助として小さめ・少なめ
- 2026年傾向：テキスト過多より「画面が静かで読みやすい」デザインが評価される

### 2-3. 表紙デザインの傾向

SNS副業・フリーランス系ジャンルでの2026年の主流：

| パターン | 効果 | 採用場面 |
|----------|------|----------|
| 文字主体（白背景＋黒文字） | 発見欄での視認性が高い。シンプルで情報が即伝わる | ノウハウ型・数字型に最適 |
| グラデーション＋白テキスト | おしゃれ感・世界観を出しやすい | ライフスタイル系掛け合わせに向く |
| スクショ風・メッセージ風 | 「リアル感」「実話感」を演出 | 体験談・DM公開・リアルな収入報告に使われる |
| イラスト／アイコン活用 | 顔出しなし運用での「キャラ立ち」に有効 | 匿名発信者が個性を出すために採用 |

→ **Tiafulへの示唆**：顔出しなしアカウントでは「文字主体（数字＋短い問いかけ）」と「イラスト・アイコンで統一感を出す表紙」の組み合わせが最も安定している

### 2-4. フォロワーがコメントしている悩み・キーワード

類似ジャンル（副業・フリーランス・在宅ワーク系）での頻出コメントパターン：

- 「私も始めたいんですが何から始めればいいですか」（入口の壁）
- 「案件取れなくてモチベ下がってます」（継続の悩み）
- 「未経験でも本当に稼げますか」（信頼の壁）
- 「スクールに入るか悩んでいます」（購入検討段階）
- 「月〇万稼げていて本当に羨ましいです」（共感・憧れ）
- 「顔出ししなくてもいいですか」（匿名で発信したいニーズ）

→ **Tiaful参考**：これらの悩みワードを冒頭に置いた企画は高コメント率になる。特に「顔出ししなくてもいいですか」という悩みは、Tiafulのターゲット像そのものであり、同時にTiafulの発信スタイル（匿名・顔出しなし）のリアルな体現になる強力な訴求軸

## 3. Tiafulへの戦略示唆

### 3-1. このジャンルで勝てそうな差別化ポイント

現状のSNS運用代行スクール市場の課題点：

| 競合の弱点 | Tiafulの差別化可能ポイント |
|-----------|--------------------------|
| Zoom必須・対面型が多い | **完全非同期・Zoom不要**（ターゲットの「育児中・働きながら」に直接刺さる） |
| 添削が形式的・薄い | **添削特化**（「なぜそのキャプションがダメか」まで言語化する高精度フィードバック） |
| 案件保証が「紹介」どまり | Tiafulは**実際にSNS運用代行で企業売上に貢献した実績**がある（講師の信頼性） |
| 発信者が顔出し前提 | **Tiaful自体が顔出しなしで発信する**ことで「私も顔出しなしでできる」を体現できる |
| 価格が低め（10万円台） | 高価格（297,000〜645,000円）でも**AIによる高精度フィードバック**という差別化が正当化される |

→ **最重要差別化軸**：「添削特化×非同期×AI補助×顔出しなしで体現」の4点セット。これは競合の誰もやっていない組み合わせ。analytics-knowhow「差別化は小さなことの積み重ね」の原則に合致。

### 3-2. 真似すべき投稿パターン

1. **数字＋タイムライン型リール**（english_hanah系）：「〇ヶ月で月○万」「受講生〇人が〇ヶ月で案件獲得」
2. **ビフォーアフター音源活用**（analytics-knowhow 付録A実例より）：「副業始める前→SNS運用代行で月30万」の変化の落差を見せる
3. **悩み代弁→解決型構成**：「SNS運用代行始めたいけど、どのスクール選べばいいか分からない人へ」という冒頭でターゲットを特定し、Tiafulの特徴を解説
4. **受講生の声・添削実例の公開**：受講生のビフォーアフターキャプション・投稿の改善例を見せることが、サービス信頼性の最速の証明になる
5. **「顔出しなしでやってみた」シリーズ**：Tiaful自体が顔出しなしで運用することで、アカウント全体が「顔出しなし副業の成立証明」になる

### 3-3. 避けるべき飽和コンテンツ

| 飽和パターン | 理由 |
|-------------|------|
| 「副業おすすめ〇選」（羅列型） | 2026年時点でSNS副業系では大量に出ており、保存率が下がってきている。差別化困難 |
| 「稼げるスキル〇選」（広い） | ジャンルが絞れていないため、アルゴリズムに「誰向けか」を認識させにくい |
| 「月収公開」単発（数字のみ） | 数字だけでは信頼されにくく、「再現性があるか」という問いに答えていないと離脱される |
| Zoom必須・ライブ重視の訴求 | Tiafulのターゲットはこれを嫌うため、逆に「Zoom不要」を先に言うのが正しい |
| 長尺（3分以上）の解説リール | 初期段階での新規リーチには不向き。教育は60〜90秒に圧縮が基本 |

### 3-4. プロフィール設計の提言

analytics-knowhow「④-3 プロフィール分析の手法」に従い、以下の4カテゴリで設計：

- **権威性**：「実際に運用代行で○社の売上を伸ばした実績」「添削特化スクール」
- **再現性**：「Zoom不要・非同期で学んだ受講生が〇ヶ月で案件獲得」
- **ターゲットの悩み代弁→ビフォーアフター**：「副業したいけど顔出し無理な30代女性へ」→「SNS運用代行で自由な働き方へ」
- **具体的な数字**：受講生数・案件獲得実績・月収達成者数

プロフィール1行目（続きを押さずに見える4行以内に収める）の案：

Zoom不要・添削特化スクールTiaful
受講生〇〇名が〇〇ヶ月で案件獲得
