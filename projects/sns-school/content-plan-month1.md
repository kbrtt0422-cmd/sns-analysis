## 企画方針の前提

### Tiafulアカウントの核心設計

- **唯一の目的**: 無料相談申込獲得（初月目標18〜20件）
- **ターゲット一人の具体像**: 30代・会社員またはパート・子育て中・「副業したいが顔出しはできない」「何のスキルを身につければいいかわからない」「スクールが多すぎて選べない」という悩みを持つ女性
- **投稿者の独自性（掛け算）**: SNS運用代行の現場実績あり × 匿名・顔出しなしでの発信 × 添削特化という他にない組み合わせ → この3点が「体現者としての証明」になる
- **1ヶ月の最終ゴール**: ①ジャンルをアルゴリズムに学習させる ②ターゲットを引き寄せるフィルタリングをかける ③DM→無料相談の導線を1本通す

## A. アカウント初期設定チェックリスト

### 投稿前に完了させること（第1投稿日の前日までに必達）

#### プロフィール設計（post-planner-knowhow ④プロフィール設計 準拠）

- [ ] **ユーザーID**: 名前を先頭に、ジャンルを後に続ける形に設定。カタカナで読みにくい英単語は避ける
  - 例案: `biora_tiaful` / `tiaful.sns` など（検索されやすさ重視）
- [ ] **アカウント名（表示名）**: 「名前 ＋ 何が得られるか（権威性×数字）」の構成で設定
  - 案: `BIORA｜SNS運用代行で稼ぐ添削スクール Tiaful`
  - または: `BIORA｜顔出しNGでSNS副業できた添削コーチ`
- [ ] **プロフィール文（bio）4行以内**: 1行目にベネフィットを置く
  ```
  顔出しNGでもSNS運用代行で稼げる
  添削特化・Zoom不要・AI補助フィードバック
  実績:○社の運用を担当・企業売上に貢献（数値開示可の範囲で）
  ▼ 無料相談はURLから → Tiaful
  ```
- [ ] **アイコン**: 顔出しなしのため、Tiafulのブランドカラーを決めてロゴ・シンボルアイコンを設定。色味は落ち着いたトーン（蛍光色・原色は避ける）。30代女性のターゲットに合う品のある配色
- [ ] **ハイライト最低3個設置**: フォロワー0人の段階でも必須（post-planner-knowhow ④⑤準拠）
  1. **「まずここ見て」**（自己紹介ではなく「なぜ今ここにいるのか」の経緯・ストーリー。過去の苦労→転機→今の逆転構造）
  2. **「添削ってこういうもの」**（実際の添削ビフォーアフターのサンプル。モザイク可。「中身が見える」信頼材料として最重要）
  3. **「よくある質問」**（「顔出しなしでできますか」「未経験でも大丈夫ですか」「Zoomはありますか」の3問に答えるだけでDM前の不安を取り除ける）

#### ジャンル学習設定（sns-knowledge-base 3-12 リールを投稿する前にやること 準拠）

- [ ] **同ジャンルの発信者を10〜30人フォロー**（1日10人程度・3日に分けて）
  - フォロー対象: SNS運用代行・副業系・フリーランス系の発信者（一般人ではなく発信者のみ）
  - 具体的候補例: 競合分析レポートで確認した @runa_freelance.life / @english_hanah 系のアカウント群
  - 目的: インスタに「このアカウントはSNS副業・運用代行ジャンル」と認識させるため
- [ ] **関連ハッシュタグを3〜5個フォロー**
  - `#SNS運用代行` `#在宅副業` `#フリーランス女子` `#SNS副業` `#副業30代` 等
- [ ] **発見欄リサーチ（15分）**: このジャンルで直近伸びているアカウント（投稿50〜100本・フォロワー5,000〜10,000人）を5つ以上特定してメモ
  - post-planner-knowhow ①「5-STEPジャンル分析法のSTEP4」に合致する確認作業

#### 投稿前の準備（sns-knowledge-base 3-6 投稿する際の注意点 準拠）

- [ ] **キャプションテンプレートを作成**: フォロー推奨文・本文・ハッシュタグのテンプレートをメモアプリに保存（毎回ゼロから考えないようにする）
- [ ] **ハッシュタグリストを準備**: ノウハウ型・体験談型・ライフスタイル型の3カテゴリで各10〜15個リスト化
- [ ] **音源リストを保存**: インスタ内でトレンドマーク（右上矢印）がついている音源を10本程度保存。アカウントの「落ち着いた30代女性向け」イメージに合うゆったりしたテンポのものを優先
- [ ] **添削ビフォーアフターのサンプルを最低3本準備**: ハイライト・投稿素材として使える形（個人情報モザイク済み）

## C. 投稿フェーズ設計

### フェーズ1（1〜4本目）：ジャンル認知・アルゴリズム学習期

**目的**: インスタのアルゴリズムに「このアカウントはSNS副業・運用代行ジャンル」と学習させること。新規リーチを最大化し、ターゲット層（副業志望の30代女性）に届ける。

**設計の思想**（sns-knowledge-base 3-12 / post-planner-knowhow ①準拠）:
- 投稿前に同ジャンルの発信者10〜30人とハッシュタグ3〜5個をフォローしてある状態で1本目を投稿する
- 最初の4本は「ジャンルキーワードを表紙・キャプションに明示的に入れる」ことを徹底する（SNS運用代行・副業・在宅・顔出しなしなど）
- アルゴリズムに「誰向けか」を認識させるための絞り込みが最優先。広く刺さろうとしない

**4本の役割分担**:
1. ジャンル説明（SNS運用代行とは何か） → 新規流入の入口
2. 差別化の宣言（顔出しなしでできる） → ターゲットフィルタリング
3. 実績証明（ビフォーアフター体験談） → 信頼の土台
4. 市場教育（スクール選び方） → Tiafulが自然に浮かぶ比較コンテンツ

**KPI目標（フェーズ1終了時）**:
- リール平均再生数: 500回以上（アカウント開始直後の現実的な目標）
- フォロー率: 0.3%以上（1本あたり）
- プロフィールアクセス率: 5%以上（フィード投稿の場合）

---

### フェーズ2（5〜9本目）：信頼構築・ファン化期

**目的**: フォローしてくれた人を「認知者」から「ファン（＝自分が求めるユーザー層）」へ引き上げる。自己開示・ライフスタイル・添削実例の3本柱で信頼を積む。

**設計の思想**（sns-knowledge-base 6-1 ファン化の目的 / 5-6 ストーリー×DM戦略 準拠）:
- ファンとは「単なるフォロワー」ではなく「BIORAの考え方・価値観・実績を知って信頼している人」
- フィード・リール投稿では「需要がある企画」を出しながら、ストーリーで「本当に届けたいこと」を発信するという二層構造を作る
- 自己開示投稿（5本目）はPREP法（結論→理由→具体例→結論）で展開する
- コメントにはなるべく「名前を呼ぶ」返信をする（sns-knowledge-base 5-6「DMの返し方」の原則をコメントにも適用）

**5本の役割分担**:
5. BIORAの自己開示（なぜやっているか・過去の苦労→今）→ファン化の入口
6. 添削実例公開 → サービス品質の証明・「中身が見える」信頼
7. 数字で語る（稼げる金額のリアル） → DM誘発の準備
8. ノウハウ提供（ミス指摘型） → 保存率最大化・有益発信者としてのポジション確立
9. ライフスタイル日常型 → コメントベイト・親近感醸成

**KPI目標（フェーズ2終了時）**:
- 保存率: ノウハウ型投稿で150%以上（いいね数比）
- コメント率向上（フェーズ1比1.5倍以上）
- DM受信数: フェーズ2合計で3〜5件以上

---

### フェーズ3（10〜16本目）：導線強化・DM誘導・無料相談申込期

**目的**: 信頼を積んだフォロワーを「無料相談申込」という行動に誘導する。DM→無料相談の導線を実際に機能させる。

**設計の思想**（sns-knowledge-base 9-5 販売導線の構築 / go-to-market 2章 集客導線 準拠）:
- 9-5の導線「リールで集客→ストーリーで教育→LINE/DM→無料相談→成約」のInstagram部分を完成させる
- フェーズ3の各投稿にはキャプション内に「無料相談はプロフURLから」というCTAを必ず入れる
- 社会的証明（受講生実例・12本目）を出すことで「本当に効果があるか」という最後の疑念を解消する
- 誠実な自己開示（後悔したこと・正直な話・1ヶ月振り返り）で「売り込まれている感」を消す

**7本の役割分担**:
10. サービスQ&A（迷っている人への回答） → DM誘発・申込前の疑念解消
11. 「稼げない人の特徴」＋自己開示 → DM対話のきっかけ作り
12. 受講生実例（数字＋ビフォーアフター） → 社会的証明・最後の疑念解消
13. 無料相談FAQ（何を聞かれるか） → 申込への心理的ハードルを下げる
14. 現役代行者の正直な話 → 信頼性の最終確認
15. スクール体験談（良い面・後悔も含む） → 誠実さでファン化を深める
16. 1ヶ月振り返り → 継続フォロワーへの感謝・次月への導線

**KPI目標（フェーズ3終了時）**:
- DM受信数: 月計10件以上
- 無料相談申込数: 月計2件以上（go-to-market KPI「初月2件」達成）
- プロフィールURLアクセス数: 月計50回以上

## D. ストーリーズ連携プラン

ストーリーズの役割: フィード・リールが「認知の場」であるのに対し、ストーリーズは「ファン化と見込み顧客の教育の場」（sns-knowledge-base 6-1 / ストーリーズの教科書 2章 準拠）。

**原則**: 「線のストーリー」として複数枚を連続させ、単発ではなく「物語」として設計する（sns-knowledge-base 10章「線のストーリーを意識する」準拠）。

### 各投稿に対応するストーリーズ

| 投稿# | ストーリーズの内容（投稿日当日または翌日） | DM誘導タイミング・方法 |
|------|----------------------------------------|---------------------|
| 1（ジャンル説明） | 「今日投稿しました」＋「SNS運用代行に興味がある方はスタンプで教えて」（アンケートスタンプ活用）。反応した人に個別DM「ありがとうございます！どんなことで悩んでいますか？」と送る | アンケート反応者への即DM誘導 |
| 2（顔出しなし宣言） | 「私も最初は顔出しなしでいけるか不安だった」という背景のリアル話を3〜5枚で展開。最後に「同じ不安がある方はDMどうぞ」 | 自然なDM誘導（不安代弁→共感→相談） |
| 3（体験談） | 「今日の投稿でも触れた『最初の案件獲得』について、もう少し詳しい話をストーリーでします」→複数枚でリール未収録の詳細を出す。最後：「詳しく聞きたい方はDMで」 | 詳細を「ストーリーだけで見られる」特別感でDM誘発 |
| 4（スクール選び方） | 「チェックリストを完全版で作ったのでDMくれた方に送ります」（特典型DM誘導）。これがTiafulで最も強力なDM誘導パターン | 特典配布型DM誘導（最も反応が取れるパターン） |
| 6（添削実例） | 「今日見せた添削ビフォーアフター、実は他にも○本あります。興味ある方はDMで一言『添削』と送ってください」 | キーワードDM誘導（「添削」と送ってもらう） |
| 7（稼げる金額） | 「自分の場合はいくらくらい稼げますか？というご質問が多いので、個別にお答えします。DMで現状を教えてもらえれば目安をお伝えします」 | 個別診断型DM誘導（最も温度が高い見込み客を拾える） |
| 8（ミス3つ） | 「今日の投稿の補足：ミスを避けるための具体的なチェックリストをDMで送ります（無料）」 | 特典配布型DM誘導 |
| 9（ライフスタイル） | 「こんな環境で作業してます」「質問があれば何でもどうぞ」というQ&A形式（質問箱スタンプ活用）→回答をストーリーで複数枚展開 | 質問箱→回答ストーリー→「もっと聞きたい方はDM」の流れ |
| 10（サービスQ&A） | 「無料相談ってどんな感じですか？と聞かれることが多いので正直に話します」→3〜5枚で無料相談の流れを説明。最後：「申込はプロフURLから」 | 申込CTAをストーリーのリンクスタンプで直接設置 |
| 12（受講生実例） | 「受講生の〇〇さんが案件取れたと連絡をくれました」（許可を得た範囲で共有）→「詳しい経緯を本人の許可を得てDMで教えます」 | 社会的証明＋DM誘導の合わせ技 |
| 13（無料相談FAQ） | 「無料相談の申込、今週は○枠あります」という枠数を見せる（希少性演出）。リンクスタンプで申込フォームへ直接誘導 | 申込フォームへのリンクスタンプ直設置（最終クロージング） |

## E. 1ヶ月後の振り返り基準

### 指標定義（competitor-analysis 前提 / analytics-knowhow準拠）

- **保存率** = 保存数 ÷ いいね数 × 100（%）
- **フォロー率（リール）** = 新規フォロワー数 ÷ リーチ数 × 100（%）
- **プロフィールアクセス率（フィード）** = プロフィールアクセス数 ÷ リーチ数 × 100（%）

### フェーズ別KPIと判断基準

| 指標 | フェーズ1目標 | フェーズ2目標 | フェーズ3目標 | 月計目標 | 判断基準（月末の判定） |
|------|------------|------------|------------|--------|-------------------|
| 保存率（ノウハウ型） | 100%以上 | 150%以上 | 150%以上 | - | 80%以下→企画テーマ・情報量を見直す。ボリューム不足または「欲しい情報でない」可能性 |
| フォロー率（リール） | 0.3%以上 | 0.3%以上 | 0.4%以上 | - | 0.2%以下→プロフィール文・入り出し（冒頭3秒）に問題。プロフ改修かリール冒頭の作り直しを優先 |
| プロフィールアクセス率（フィード） | 5%以上 | 5%以上 | 5%以上 | - | 3%以下→フィード表紙の改善または「この投稿を誰が出しているか」への興味喚起が足りない |
| DM受信数 | 1〜2件 | 3〜5件 | 5件以上 | 10件以上 | 月計5件以下→ストーリーのDM誘導CTAを毎投稿後に必ず設置できているか確認。特典型DM誘導（チェックリスト等）を追加実施 |
| 無料相談申込数 | 0件 | 0〜1件 | 2件以上 | 2件以上 | 0件の場合→投稿→DM→申込の導線の「どこで詰まっているか」を確認。①DMは来ているがフォームに行かない→フォーム導線を簡略化 ②DMも来ていない→ストーリーのCTA設計を見直す |

### フェーズ別の振り返り設問

**フェーズ1（1〜4本目終了後）の確認事項**
1. 同ジャンルのフォロワー増（フォロワー属性に副業・フリーランス関心層が含まれているか）
2. 発見欄からの流入リーチが確認できているか
3. アカウントジャンルがインサイトの「リーチしたアカウントの属性」にSNS・副業系が出ているか

**フェーズ2（5〜9本目終了後）の確認事項**
1. コメント内容が「共感型」「質問型」「フォロー宣言型」に変化しているか（認知→ファン化の証拠）
2. DM数が増加しているか
3. 保存数が多かった投稿の「なぜ保存されたか」の要素分解（sns-knowledge-base 3-5 企画の作り方「要素を見ていくことが大切」に基づき、バズった要素を次の企画に反映）

**フェーズ3（10〜16本目終了後）の確認事項**
1. 無料相談申込数と申込者のDM内容の傾向（どの投稿・ストーリーがきっかけになったか）
2. DM→フォーム申込の転換率（DMは来るがフォームに行かない場合はフォーム誘導文言の改善）
3. 「どの投稿を見て来たか」を無料相談で必ず聞く（最も効果的な企画の特定）

### 1ヶ月後の判断基準（継続方針の分岐）

| シナリオ | 判断 | 次のアクション |
|---------|------|-------------|
| 無料相談2件以上 ＋ DM10件以上 | 導線は機能している | フェーズ1〜3の各企画の「伸び指標」上位3本を特定し、同テーマの「見せ方を変えた」類似企画を2本目として仕込む（sns-knowledge-base 3-5「見せ方を変える」） |
| 無料相談0〜1件 ＋ DM5件以上 | DM→申込の転換が弱い | 無料相談への誘導文言・フォームの簡略化・ストーリーでの申込リンク直設置を優先改善 |
| DM5件未満 | ストーリーのDM誘導が弱い | 特典型DM誘導（チェックリスト・Q&A回答配布等）を翌月初週に集中実施 |
| リール再生数が全体的に伸びない | 企画またはアルゴリズム認識の問題 | 最もリーチした投稿の「冒頭3秒・表紙・音源」を分析し、他投稿に横展開。競合のバズ投稿の「要素分解」を再実施してジャンルの勝ちパターンを再確認 |

## 補足：リール制作の基本原則（各投稿に共通）

sns-knowledge-base 3-6「投稿する際の4つの注意点」および競合分析 2-2「伸びているリールの共通パターン」より、全投稿共通で徹底すること。

**冒頭3秒の原則**:
- 数字型: 「〇ヶ月で月〇万」「未経験から〇日で」
- 悩み代弁型: 「副業したいけど顔出しはできない、という人へ」
- 禁止/警告型: 「このやり方、間違ってます」
- いずれの場合も「30代・副業志望・顔出しNG女性が自分のことを言われている」と感じる一文を必ず冒頭に置く

**テンポと尺**:
- 教育系ノウハウ型: 60〜90秒
- 共感・体験談型: 45〜60秒
- 最初の数本は短め（45秒以下）からテストして、リプレイ率の高いものを把握してから尺を伸ばす

**テロップ（顔出しなし運用）**:
- 1カットに15文字以内・大きめフォントで読みやすく
- テキスト過多よりも「画面が静かで読みやすい」デザインを優先（competitor-analysis 2-2 2026年傾向）

**音源**:
- インスタ内でトレンドマーク（右上矢印）付き音源を使う
- アカウントのターゲット（落ち着いた30代女性）に合うゆったりしたテンポのものを選択
- アフレコありの場合: アフレコ100%・音楽1〜5%

**キャプション構成**（sns-knowledge-base 3-6「②キャプションの記入」準拠）:
1. フォロー推奨部分（1行目・リール表示から即見える）: `＠[アカウントID] ←SNS運用代行で稼ぐ添削スクールTiaful`
2. 本文: 投稿で触れられなかった補足・詳細
3. フォロー文: 「この内容が役に立ったらフォローしてください」
4. ハッシュタグ: 10〜15個（ジャンル系・副業系・在宅系を混在）
