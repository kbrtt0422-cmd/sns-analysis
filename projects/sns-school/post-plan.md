# 非対面・添削特化型SNSスクール 投稿企画（立ち上げ〜3ヶ月）

## 0. 前提整理

### ターゲット（一人の実在人物像まで具体化）
- **メイン**：会社員（28〜35歳）、副業でInstagram/SNS運用代行・コンテンツ販売を目指している。
  「スキルスキップ」等のSNS講座に興味はあるが、高額で「結局自分でやるしかない」「個別に見てもらえるか不安」という不信感を持っている。
- **行動特性**：X・Instagramでノウハウ系発信者をフォロー済み、無料コンテンツは一通り見尽くしている。
  欲しいのは「情報」ではなく「自分の投稿のどこが悪いかを具体的に直してもらえる場」。
- **悩みの代弁ワード**：「何が正解かわからないまま投稿し続けている」「コンサルは高いし、結局放置される」「顔出し講師に依存したくない／顔出しが苦手」

### コンセプト（狭く深く）
**「自分では気づけない投稿の”ズレ”を、人ではなく仕組みで毎回正確に直してもらえるスクール」**
- 競合（インフルエンサー系スクール）の弱点＝「講師個人のセンス・体力に依存」「人気講師は手が回らず添削が薄くなる」を逆手に取る。
- 顔出しなしで戦う以上、**信頼の源泉を「個人の権威」ではなく「添削の証拠（Before/After）」「仕組みの再現性」**に置く。これがアカウントの突出軸。

### 突出させる1〜2要素（4要素：企画・編集・世界観・独自性）
- **企画力を100点**：添削サンプル・Before/After・添削基準の言語化を毎回出せる「ネタの継続性」を最優先。
- **独自性を100点**：「インフルエンサー型と違い、AIが個別カリキュラムを自動生成する」というタイミング（AI活用の先行者利益）＋「属人化しない仕組み」のギャップを前面に。
- 世界観・編集は60点で良い（顔出し不要、ブランドカラー・テロップ統一の最低限でOK）。

### 独自性の作り方（強みの掛け算 / ギャップ / タイミング）
- 掛け算：「添削特化」×「非対面・非同期」×「AIによる個別カリキュラム」×「高単価でも仕組み化」＝レアな立ち位置。
- ギャップ：「顔出しインフルエンサーが教えるのが当たり前」という業界常識に対し、**「先生の”やる気”や”手の空き”に左右されない添削」**を逆説的に訴求。
- タイミング：SNS運用代行・コンテンツ販売の副業ブームに対し、「個別添削×AI」を掲げる競合はまだ少ない今がチャンス（先行者ポジション）。

## 1. 投稿軸（カテゴリ設計）

顔出しなしで信頼を獲得するため、以下5軸を使い回す。Xはテキスト＋スクショ中心、Instagramはリール／画像で同じ素材を再構成する想定。

| 軸 | 内容 | 信頼獲得の狙い |
|---|---|---|
| **A. 添削ビフォーアフター** | 受講生（or サンプル）の投稿を添削前→添削後で見せる | 「効果が見える」＝添削の質を証拠で示す |
| **B. 添削基準の言語化** | 「なぜそれがダメなのか」を添削者の視点で解説 | 属人的センスではなく仕組み・基準があることを示す |
| **C. よくあるNGパターン集** | ターゲットが無意識にやっている失敗を指摘 | 悩みの代弁→「これ私だ」という当事者化 |
| **D. AI個別カリキュラムの裏側** | AIがどう個別最適化するかの仕組み紹介（顔出し不要） | 「人力の限界」を超えた差別化の説明 |
| **E. 業界への問題提起・逆説** | 「インフルエンサー型講座の限界」を指摘する意見発信 | ギャップで独自性を強調、X特有の伸びやすいフォーマット |

各投稿の最後に無料相談CTAを必ず添える（詳細は5章）。

## 2. 月別テーマの骨子

### 1ヶ月目：認知・信頼の土台作り（proof content優先、CTAは緩やかに）
- 目的：いきなり売り込まず、「添削の質」の証拠を積む。ノウハウにある「実績を先に積んでから本格始動」の考え方を踏襲。
- 比重：A・B・C中心（70%）、D・E控えめ（30%）
- Before/Afterのサンプルが少ない場合は、**公開添削（既存の有名アカウントの投稿を本人の許可なく一般論として添削する/もしくは自作の悪い例を用意）**で代替し、初期のネタ切れを防ぐ。

### 2ヶ月目：仕組み訴求・比較訴求の強化
- 目的：「なぜインフルエンサー型講座ではダメなのか」を明示し、比較で選ばれる立ち位置を作る。
- 比重：D・Eを増やす（A・B・Cと半々）。
- 「添削の質を支える仕組み（AIカリキュラム生成のロジック・添削担当の体制）」を具体的に見せ、高単価（30〜50万）への納得感を積む。

### 3ヶ月目：相談直結・社会的証明の強化
- 目的：申込みボトルネックの解消。受講生の声・成果・KAZUの無料相談で何が得られるかを明確化。
- 比重：A（成果報告型）・受講生インタビュー的コンテンツ・CTA直結企画を増やす。
- 「無料相談で何が分かるか」を具体的に説明する投稿を週1本固定で入れる。

### 1ヶ月目

1. 「人気講師の添削が”雑”になる理由。属人化の限界を構造で説明」（問題提起・X）

## 5. 無料相談への導線（CTA設計）

### 基本方針
- 毎投稿にCTAを入れるのではなく、**情報投稿（A〜D）は「気づき提供」までに留め、固定ポストとプロフィールbioで常時CTAを効かせる**のが基本（売り込み過多で信頼を損なわない）。
- 週1本は明確にCTAを主役にした投稿を入れる（日曜のCTA強化投稿、3ヶ月目はCTA直結企画を増量）。

### CTAパターン
1. **ソフトCTA（通常投稿の最後）**：「こういう添削を非対面でやっています。気になる方はプロフィールのリンクから」
2. **固定ポスト／プロフィールbio**：「無料相談はこちら→（フォームリンク）」を常設。bio1行目は「ベネフィット」を訴求（例：「”なぜ伸びないか”が初めて分かる添削スクール」）。
3. **ハードCTA（週1・成果報告系投稿）**：「同じように添削を受けたい方は、まず無料相談で現状を診断します→リンク」
4. **リプライ・引用での誘導**：伸びた投稿には「個別に見てほしい方はDMか固定ポストのリンクから無料相談へ」と返信で誘導。
5. **無料相談の”中身”を見せる投稿（3ヶ月目強化）**：相談で何が分かるかを具体的に書くことで、フォーム到達後の離脱（怖さ・不明確さ）を減らす。担当KAZUの役割を「個別の現状診断」として明示。

### 注意点
- 顔出しなしのため、CTA文中で「個人の権威」に頼らず「添削という行為そのものの価値」「データ・Before/After」を訴求軸にすること。
- フォーム遷移後の期待値ズレを防ぐため、CTA文言と無料相談の実際の内容（KAZUが何をするか）を一致させる。

## 6. 今後の運用メモ（次回企画への引き継ぎ）

- 初期はBefore/Afterの実例ストックが少ない可能性が高い。立ち上げ前に自作サンプル添削を5〜10本ストックしておくと初月のネタ切れを防げる。
- X投稿の反応（いいね・リポスト数）を週次で見て、A（添削Before/After）とE（問題提起）のどちらが伸びるかで2ヶ月目の比重を調整する。
- 受講生が出てきた段階で、必ずA軸（Before/After）とCTA直結企画（3ヶ月目型）の比重を増やす。
