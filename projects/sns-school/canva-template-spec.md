## 事前準備：ブランドキットの設定

Canvaを開いたら最初にブランドキットを設定する。

### カラー登録

「ブランドキット」→「ブランドカラー」→「+カラーを追加」から以下を5色登録：

```
Cream  : #F5F0E8
Gold   : #C9A96E
White  : #FFFFFF
Sand   : #E0D4BC
Deep   : #1A1714
```

### フォント登録

「ブランドキット」→「ブランドのフォント」で以下を登録：

| 役割     | Canvaフォント名         | スタイル          |
|----------|-------------------------|-------------------|
| 見出し   | Playfair Display        | Regular / Bold    |
| サブ     | Montserrat              | Light / Regular   |
| 本文     | Noto Sans JP            | Light / Regular   |

## テンプレート 1：Instagram 正方形投稿（1080×1080）

### Canva設定
- テンプレートサイズ: **「Instagramの投稿」** を選択（自動で1080×1080になる）
- 背景色: **#F5F0E8（Cream）**

### レイアウト仕様

```
┌──────────────────────────────┐  ← 1080px
│                              │
│  ←60px│                │60px→│
│       ─────────────────       │ ← Goldの横線（高さ2px / #C9A96E）（上から180px付近）
│                              │
│   [ラベルテキスト]            │ ← 上から210px、左端から80px
│                              │
│   [メインコピー]             │ ← 上から280px、左端から80px
│                              │
│   [サブコピー]               │ ← メインコピーの40px下
│                              │
│       ─────────────────       │ ← Goldの横線（高さ2px）（下から180px付近）
│                              │
│   TIAFUL                    │ ← 下から80px、右揃え
└──────────────────────────────┘
```

### 各要素の設定値

| 要素             | フォント            | サイズ | カラー  | 設定                          |
|------------------|---------------------|--------|---------|-------------------------------|
| ラベルテキスト   | Montserrat Light    | 18pt   | #C9A96E | 大文字ON、文字間隔: 5         |
| メインコピー     | Playfair Display    | 58pt   | #1A1714 | 行間: 1.3、最大2行            |
| サブコピー       | Noto Sans JP Light  | 26pt   | #1A1714 | 行間: 1.8、最大3行            |
| ブランド名(TIAFUL) | Playfair Display  | 20pt   | #C9A96E | 大文字ON、文字間隔: 8         |
| Goldライン       | 線ツール            | 高さ2px | #C9A96E | 幅: キャンバス幅から左右80px引いた長さ |

### 外側の余白（すべての要素のガイドライン）
- 上下左右の端から最低 **60px** は空ける
- テキストブロックは左端から **80px** の位置に揃える

### バリエーション

**A. テキスト中心型（お知らせ・名言・ノウハウ）**
- 背景: Cream (#F5F0E8)
- 上下にGoldライン
- メインコピー + サブコピーの2段構成

**B. 写真背景型（ライフスタイル・実績）**
- 写真を全面配置 → 上から半透明Cream(#F5F0E8、透明度60%)をオーバーレイ
- テキストはDeep (#1A1714) で乗せる
- 右下にTIAFULのロゴ

**C. カード型（リスト・ステップ解説）**
- 背景: Cream (#F5F0E8)
- 中央にWhite (#FFFFFF) の角丸カード（角丸: 8px、Sand #E0D4BC で枠線1.5pt）
- カード内にテキストを配置

## テンプレート 2：Instagram Stories（1080×1920）

### Canva設定
- テンプレートサイズ: **「Instagramのストーリー」** を選択（自動で1080×1920になる）
- 背景色: **#F5F0E8（Cream）**

### レイアウト仕様

```
┌──────────────────────────────┐  ← 1080px
│                              │
│   TIAFUL                    │ ← 上から120px、右揃え（右から60px）
│                              │
│   ─────────────────          │ ← Goldライン（上から200px）
│                              │
│                              │
│   [ラベルテキスト]            │ ← 上から250px、左端80px
│                              │
│   [メインコピー]             │ ← 上から320px、左端80px
│                              │
│   [サブコピー]               │ ← メインの50px下
│                              │
│                              │
│   ─────────────────          │ ← Goldライン（下から320px）
│                              │
│   [CTA テキスト]             │ ← 下から240px、中央揃え
│   [CTAボタン]                │ ← 下から150px、中央揃え
│                              │
└──────────────────────────────┘
```

### 各要素の設定値

| 要素              | フォント            | サイズ | カラー  | 設定                        |
|-------------------|---------------------|--------|---------|------------------------------|
| ブランド名(TIAFUL) | Playfair Display   | 22pt   | #C9A96E | 大文字ON、文字間隔: 8        |
| ラベルテキスト    | Montserrat Light    | 20pt   | #C9A96E | 大文字ON、文字間隔: 5        |
| メインコピー      | Playfair Display    | 64pt   | #1A1714 | 行間: 1.3、最大3行           |
| サブコピー        | Noto Sans JP Light  | 28pt   | #1A1714 | 行間: 1.8                    |
| CTAテキスト       | Montserrat Light    | 18pt   | #1A1714 | 大文字ON、中央揃え           |
| CTAボタン背景     | 角丸四角形          | -      | #1A1714 | 角丸8px、幅480px、高さ72px  |
| CTAボタン文字     | Montserrat Regular  | 18pt   | #F5F0E8 | 大文字ON、中央揃え、文字間隔: 3 |

### Stories用補足

- スワイプアップ誘導がある場合は一番下（下から80px）に「↑ プロフィールのリンクから」と小さく入れる（Noto Sans JP Light / 18pt / #C9A96E）
- 画像を使う場合は上部40%に画像、下部60%にCreamテキストエリアを配置する「上下分割レイアウト」が使いやすい

## テンプレート 3：教材スライド（16:9 / 1920×1080）

### Canva設定
- テンプレートサイズ: **「プレゼンテーション（16:9）」** を選択（1920×1080）
- 背景色: **#FFFFFF（White）**

### スライドレイアウト仕様

#### 表紙スライド
```
┌────────────────────────────────────────┐
│   背景: Cream (#F5F0E8)               │
│                                        │
│   TIAFUL              （右上 / 30pt）  │
│   ─────────────────────（Gold線）──── │
│                                        │
│        [スライドタイトル]              │ ← 中央 / 64pt / Deep
│        [サブタイトル]                 │ ← 36pt / Deep
│                                        │
│   ─────────────────────（Gold線）──── │
│   第◯章 / 2026.07                     │ ← 右下 / 18pt / Gold
└────────────────────────────────────────┘
```

#### 本文スライド（テキスト中心）
```
┌────────────────────────────────────────┐
│   背景: White (#FFFFFF)               │
│  ┌─────────────────────────────────┐  │
│  │ 見出し（左上 Gold下線あり）      │  │
│  └─────────────────────────────────┘  │
│                                        │
│  ・ポイント1                           │
│  ・ポイント2                           │
│  ・ポイント3                           │
│                                        │
│  ─────────────── TIAFUL ──────────── │ ← フッター（Gold / 14pt）
└────────────────────────────────────────┘
```

#### 強調スライド（重要ポイント）
```
┌────────────────────────────────────────┐
│   背景: Deep (#1A1714)                 │
│                                        │
│        [キーメッセージ]                │ ← 中央 / 52pt / White
│        （短文・インパクト重視）        │
│                                        │
│        ─── Gold line ───              │
│        [補足テキスト]                 │ ← 26pt / #C9A96E
└────────────────────────────────────────┘
```

### 各要素の設定値（教材スライド）

| 要素               | フォント            | サイズ  | カラー  | 設定                      |
|--------------------|---------------------|---------|---------|---------------------------|
| スライドタイトル   | Playfair Display    | 52〜64pt | #1A1714 | 行間: 1.3                |
| 見出し（本文ページ）| Playfair Display   | 36pt    | #1A1714 | 下線: Gold 2px           |
| 箇条書き本文       | Noto Sans JP Light  | 24pt    | #1A1714 | 行間: 1.8、左から120px   |
| 強調文字           | Playfair Display    | 52pt    | #F5F0E8 | Deep背景上               |
| フッター           | Montserrat Light    | 14pt    | #C9A96E | 大文字ON、中央揃え        |
| スライド番号       | Montserrat Light    | 14pt    | #C9A96E | 右下配置                  |

### 余白ルール（1920×1080）
- 左右マージン: **80px** 以上
- 上部マージン: **80px**（ヘッダーとコンテンツの間も80px）
- 下部フッターエリア: 下から **60px** まで

## 共通のフォントまとめ（Canvaで検索するフォント名）

| 用途        | Canvaで検索するフォント名     | 備考                              |
|-------------|-------------------------------|-----------------------------------|
| 英語見出し  | `Playfair Display`            | 無料で使える / セリフ体           |
| サブ見出し  | `Montserrat`                  | Light または Regular を使う       |
| 日本語本文  | `Noto Sans JP`                | Light を基本とする                |
| 英語本文    | `Lato`                        | Light または Regular              |
| 代替英語見出し | `EB Garamond`              | Playfair が合わない時の代替       |

## テンプレート作成チェックリスト

テンプレートを作り終えたら以下を確認する：

- [ ] 背景色がブランドカラーから選ばれているか
- [ ] フォントが3種類以内に抑えられているか
- [ ] Goldの使用面積が全体の20%以内か
- [ ] 左右の余白が60px以上確保されているか
- [ ] 英語のブランド名は大文字(TIAFUL)になっているか
- [ ] 旧ブランド色（水色・ピンク・紫）が混入していないか
- [ ] テキスト量が多すぎず、パッと読めるか
- [ ] フォントサイズがスマホで読める大きさか（最小18pt以上）
